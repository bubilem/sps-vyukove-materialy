Modelový orientovaný vážený graf se 4 uzly

Konkrétní ukázkový graf, na kterém si krok za krokem vysvětlíme veškeré datové struktury a programové operace.

4 uzly {0, 1, 2, 3} • 5 orientovaných hran s váhami

Vlastnosti našeho modelu

  • Uzly (V): Celkem 4 vrcholy očíslované od 0 do 3 (ideální pro přímé indexování v programovacích jazycích).
  • Orientace (Digraf): Šipka udává směr toku z výchozího uzlu $u$ do cílového uzlu $v$. Např. hrana $0 \to 1$ neznamená, že existuje cesta $1 \to 0$!
  • Ohodnocení (Váhy): Každá hrana nese číselnou hodnotu (např. délka kabelu v metrech, cena letenky, čas v minutách).
E = { (0, 1): 5, (0, 2): 3, (1, 2): 2, (2, 3): 7, (3, 0): 1 } Množina orientovaných hran s příslušnými váhami

Matice sousednosti (Adjacency Matrix)

Čtvercová tabulka velikosti N × N, která přesně a jednoznačně popisuje všechny spoje v grafu.

u \ v 0 1 2 3
0 0 5 3 0
1 0 0 2 0
2 0 0 0 7
3 1 0 0 0
Číslo > 0 = Váha hrany (u → v)
0 = Hrana neexistuje

Základní pravidla čtení matice

  • Index řádku $u$ (Odkud): Vyjadřuje zdrojový uzel, ze kterého hrana vychází.
  • Index sloupce $v$ (Kam): Vyjadřuje cílový uzel, do kterého hrana vstupuje.
  • Buňka $M[u][v]$:
    • Pokud je hodnota $> 0$, existuje přímá hrana $u \to v$ s danou vahou.
    • Pokud je hodnota $= 0$, přímé spojení mezi uzly neexistuje.
  • Příklad čtení: V řádku 0 je ve sloupci 1 hodnota 5. To znamená: existuje hrana z uzlu 0 do uzlu 1 s váhou 5.

Od matematické matice k 2D poli v Pythonu

V Pythonu reprezentujeme matici jako vnořený seznam (list v listu), indexovaný přímo od nuly.

Python 3 # Matice sousednosti zapsaná jako 2D list matrix = [ [0, 5, 3, 0], # Řádek 0 (hrany z uzlu 0) [0, 0, 2, 0], # Řádek 1 (hrany z uzlu 1) [0, 0, 0, 7], # Řádek 2 (hrany z uzlu 2) [1, 0, 0, 0] # Řádek 3 (hrany z uzlu 3) ] # Přístup k hodnotě: matrix[odkud][kam] vaha = matrix[0][1] # Vrátí 5

První závorka [u] vybere řádek, druhá závorka [v] vybere prvek v daném řádku.

Častá začátečnická chyba: [[0] * n] * n

Tento zápis zkopíruje pouze odkazy na stejný vnitřní seznam! Změna v m[0][1] by se nechtěně projevila ve všech řádcích najednou.

Správná tvorba prázdné matice N × N nul
matrix = [[0 for _ in range(n)] for _ in range(n)]

List comprehension vytvoří $N$ samostatných a nezávislých řádků v paměti počítače.

Třída Graph v OOP: Konstruktor a Reset

Zabalení dat a souvisejících operací do přehledného objektu pro čistý a znovupoužitelný kód.

graph.py class Graph: def __init__(self, n): """Konstruktor: n je počet uzlů grafu (0 až n-1).""" self.n = n # Vytvoření prázdné matice sousednosti n x n vyplněné nulami self.matrix = [[0 for _ in range(n)] for _ in range(n)] def reset(self): """Vyčistí graf: smaže všechny hrany nastavením na 0.""" for r in range(self.n): for c in range(self.n): self.matrix[r][c] = 0

Objektová architektura

Atributy instance:

  • self.n: Uložený celkový počet uzlů v grafu.
  • self.matrix: Vnitřní 2D seznam uchovávající váhy hran.

Proč metoda reset()?

Umožňuje rychle vyprázdnit existující graf bez nutnosti znovu vytvářet novou instanci a zatěžovat garbage collector.

Práce s hranami: Přidání, hodnota a test existence

Základní stavební kameny pro manipulaci s grafem: bezpečný zápis a bleskové dotazování v čase O(1).

Metody třídy Graph def add_edge(self, u, v, weight=1): """Nastaví orientovanou hranu z uzlu u do uzlu v s danou vahou.""" if 0 <= u < self.n and 0 <= v < self.n: self.matrix[u][v] = weight else: print(f"Chyba: Neplatný index uzlu ({u} nebo {v})!") def remove_edge(self, u, v): """Odstraní hranu u -> v (nastaví váhu zpět na 0).""" self.add_edge(u, v, weight=0) def get_edge(self, u, v): """Vrátí váhu hrany u -> v (nebo 0, pokud neexistuje).""" return self.matrix[u][v] def has_edge(self, u, v): """Vrátí True, pokud hrana u -> v existuje (váha > 0).""" return self.matrix[u][v] > 0

Časová složitost: O(1)

Matice sousednosti exceluje v rychlosti přímého přístupu:

has_edge(u, v) → O(1) Blesková odezva bez procházení prvků

Nemusíme prohledávat žádný seznam – počítač skočí přímo na paměťovou adresu matrix[u][v].

Základní grafové operace: Následníci a stupně uzlů

Jednoduché a přímočaré algoritmy pro analýzu zapojení jednotlivých vrcholů.

Analytické metody def get_neighbors(self, u): """Vrátí seznam všech uzlů, do kterých vede hrana z uzlu u.""" neighbors = [] for v in range(self.n): if self.matrix[u][v] > 0: neighbors.append(v) return neighbors def out_degree(self, u): """Výstupní stupeň: počet hran vycházejících z uzlu u.""" return len(self.get_neighbors(u)) def in_degree(self, v): """Vstupní stupeň: počet hran vstupujících do uzlu v (projdeme sloupec).""" count = 0 for u in range(self.n): if self.matrix[u][v] > 0: count += 1 return count

Princip v matici

Výstupní stupeň (Out-degree):

Procházíme řádek $u$ a počítáme buňky $> 0$.

Vstupní stupeň (In-degree):

Procházíme sloupec $v$ shora dolů a počítáme buňky $> 0$.

Složitost operací: O(N) Prohledání jednoho celého řádku či sloupce

Formátovaný výpis a vzorový program

Elegantní tisk matice do terminálu a ukázka sestavení modelového grafu v praxi.

print_matrix() & main def print_matrix(self): """Přehledně vytiskne matici sousednosti s hlavičkou.""" print(" " + " ".join(f"{c}" for c in range(self.n))) print(" +" + "---" * self.n) for r in range(self.n): row_str = " ".join(f"{self.matrix[r][c]}" for c in range(self.n)) print(f"{r} | {row_str}") # === Vytvoření modelového grafu ze snímku 2 === g = Graph(4) g.add_edge(0, 1, weight=5) g.add_edge(0, 2, weight=3) g.add_edge(1, 2, weight=2) g.add_edge(2, 3, weight=7) g.add_edge(3, 0, weight=1) g.print_matrix()

Výstup v konzoli

0 1 2 3 +------------ 0 | 0 5 3 0 1 | 0 0 2 0 2 | 0 0 0 7 3 | 1 0 0 0

Testovací dotazy:

print(g.has_edge(0, 1)) # True print(g.has_edge(1, 0)) # False (orientovaný!) print(g.get_neighbors(0)) # [1, 2] print(g.out_degree(0)) # 2 print(g.in_degree(2)) # 2 (vstupují z 0 a 1)

Klíčová shrnutí & Kontrolní otázky

Strukturované zhodnocení vlastností matice sousednosti a ověření pochopení látky.

Hlavní výhody matice

  • Okamžitý test hrany $O(1)$: Zjištění existence i váhy matrix[u][v] v jediném procesorovém taktu.
  • Extrémně snadná implementace: Vystačíme si se základním vnořeným seznamem bez pointerů.
  • Skvělá pro husté grafy: Kde je většina hran zapojena a matice se plně využije.

Nevýhody a limity

  • Paměťová náročnost $O(N^2)$: Pro 100 000 uzlů potřebujeme tabulku o 10 miliardách buněk (většinou samé nuly – řídký graf).
  • Hledání sousedů trvá $O(N)$: I když má uzel jen 1 souseda, musíme zkontrolovat všech $N$ sloupců v řádku.
  • Nelze uložit násobné hrany: Mezi dvěma uzly může buňka držet jen jediné číslo.

1. Co znamená, když má orientovaný graf na pozici [2][0] hodnotu 0?

Znamená to, že neexistuje žádná přímá orientovaná hrana vedoucí z uzlu 2 do uzlu 0.

2. Jak zjistíme vstupní stupeň uzlu 3 v matici sousednosti?

Projdeme sloupec číslo 3 shora dolů (přes všechny řádky u) a spočítáme, kolik buněk má hodnotu větší než 0.

3. Proč je zápis [[0]*n]*n v Pythonu nebezpečný?

Vytvoří $n$ odkazů na jeden a tentýž vnitřní seznam. Když pak změníte prvek m[0][1] = 5, změní se hodnota ve sloupci 1 pro úplně všechny řádky grafu!

4. Kdy je lepší použít matici sousednosti místo seznamu sousedů?

U hustých grafů (kde existuje většina možných hran) a v úlohách, kde klíčový algoritmus neustále testuje existenci hrany mezi libovolnými dvěma uzly v čase $O(1)$.
