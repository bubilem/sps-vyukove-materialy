Co je programovací jazyk?

Formální komunikační systém s přísnými pravidly pro vyjádření algoritmů a výpočtů.

Formální pravidla

Syntaxe (Forma kódu)

Syntaxe určuje gramatická a pravopisná pravidla jazyka – jaké symboly, klíčová slova, závorky a interpunkce smějí být použity a v jakém pořadí.

// Syntaktická chyba (SyntaxError):
if x > 5 {  // Chybí závorka podmínky v C/JS
  print "Ahoj"  // Překladač kód odmítne
Logický význam

Sémantika (Význam kódu)

Sémantika vyjadřuje logický smysl operací – co program ve skutečnosti dělá během svého běhu. Kód může být syntakticky 100% v pořádku, ale sémanticky chybný (obsahuje logický bug).

// Sémantická chyba (Logický bug):
function calculateAverage(a, b) {
  return a + b / 2;  // Chybí závorky: (a + b) / 2
}

Dělení podle úrovně abstrakce

Čím vyšší úroveň abstrakce, tím blíže je jazyk lidskému myšlení a dále od konkrétních křemíkových registrů.

Nízkoúrovňové jazyky (Low-Level)

Přímo svázané s fyzickou architekturou daného procesoru (x86_64, ARM, RISC-V).

  • Strojový kód: Přímé binární instrukce čtené řadičem CPU (např. 01001000 10001001).
  • Jazyk symbolických adres (Assembler): Mnemotechnické instrukce (MOV, ADD, JMP) přímo manipulující s registry CPU a adresami RAM.
  • Výhody / Nevýhody: Maximální kontrola a rychlost, ale nulová přenositelnost na jiný procesor a extrémní složitost psaní.

Vysokoúrovňové jazyky (High-Level)

Odpoutané od hardware detailů. Vývojář pracuje s proměnnými, třídami, funkcemi a strukturami.

  • Systémové & střední: C, C++, Rust – umožňují přímou práci s pamětí (ukazatele), ale nabízejí bohaté abstrakce.
  • Aplikační & skriptovací: Python, JavaScript, C#, Java, Go – automatická správa paměti (Garbage Collector), vysoká produktivita.
  • Výhody: Snadná čitelnost, přenositelnost mezi operačními systémy a obrovská rychlost vývoje.

Jak se kód vykonává: Překladače a Interprety

Jakým způsobem se lidsky čitelný text promění v běh na procesoru.

Kompilace (AOT)

Kompilované jazyky

Celý zdrojový kód se před spuštěním naráz přeloží kompilátorem do nativního binárního spustitelného souboru (.exe, ELF).

C, C++, Rust, Go
• Bleskový běh, ale závislost na OS
Čistá interpretace

Interpretované jazyky

Program čte přímo interpret řádek po řádku za běhu a okamžitě jej vykonává bez předchozího uložení do binárního souboru.

Bash, starý Basic, Ruby
• Okamžitý start, ale pomalejší běh
Hybridní model & JIT

Bytecode & Virtuální stroj

Kód se přeloží do univerzálního bytecode, který pak virtuální stroj (JVM, .NET CLR, V8) za běhu dynamicky optimalizuje (Just-In-Time).

Java, C#, Python, JavaScript
• Skvělá přenositelnost a vysoký výkon

Typové systémy: Statické vs. Dynamické, Silné vs. Slabé

Jak jazyk zachází s informací o tom, jaká data jsou uložena v proměnné.

Statické + Silné

C#, Java, Rust, TypeScript

Typ každé proměnné je znám v době kompilace. Překladač nedovolí nesmyslné operace a vyžaduje explicitní přetypování.

int age = 20; // age = "ahoj" způsobí chybu
Dynamické + Silné

Python, Ruby

Typ proměnné se zjišťuje až za běhu programu. Jazyk však nedovolí automatické sčítání nekompatibilních typů.

x = 10; x = "text" (OK) | 5 + "10" → TypeError!
Statické + Slabé

C, C++ (částečně)

Typy jsou kontrolovány kompilátorem, ale programátor může pomocí přetypování ukazatelů přepsat data bez varování.

float *p = (float*)&intVal; // nebezpečný re-cast
Dynamické + Slabé

JavaScript, PHP (historicky)

Typy jsou proměnlivé a runtime provádí automatické implicitní přetypování (type coercion), což může vést k překvapením.

"5" + 2 → "52" | "5" - 2 → 3

Programovací paradigmata: Styl myšlení

Paradigma určuje základní přístup k modelování problému a strukturování kódu.

Imperativní přístup (JAK to udělat)

Programátor krok za krokem diktuje sekvenci operací a explicitně mění stav paměti počítače.

  • Procedurální (C, Pascal): Kód je organizován do funkcí a procedur manipulujících se sdílenými daty.
  • Objektově orientované (Java, C#, C++): Svět se modeluje jako komunikující objekty spojující stav (atributy) a chování (metody).

Deklarativní přístup (CO má být výsledkem)

Programátor popisuje požadovanou vlastnost výsledku a engine jazyka sám určí nejvhodnější postup.

  • Funkcionální (Haskell, Elixir, Lisp): Výpočet je chápán jako vyhodnocení matematických funkcí bez vedlejších efektů (neměnnost dat / immutability).
  • Dotazovací & Značkovací (SQL, HTML/CSS): SELECT * FROM users WHERE active = 1; – motor databáze sám zvolí optimální algoritmus indexu.

Katalog dominantních jazyků dneška

Každý jazyk vyniká v jiné doméně. Univerzální „nejlepší“ jazyk neexistuje.

Python AI / Data / Skripty

Extrémně čitelná syntaxe, gigantická vědecká komunita (NumPy, PyTorch). Standard pro umělou inteligenci a automatizaci.

JavaScript & TS Web / Frontend / Node

Jediný nativní jazyk všech webových prohlížečů. TypeScript přidává silné typování pro rozsáhlé aplikace.

PHP (8+) Web / Backend / Moderní 8+

Pohání přes 75 % webu. Ve verzi 8+ prošlo renesancí: JIT kompilátor, striktní typový systém, match výrazy a readonly třídy. Páteř enterprise frameworků (Laravel, Symfony).

C# & Java Enterprise / Backend

Robustní virtuální stroje, skvělé IDE nástroje, obrovské bankovní a podnikové systémy, Android (Kotlin/Java).

C & C++ Systémy / Hry / IoT

Maximální výkon a nízká latence. Jádra operačních systémů, herní enginy (Unreal), embedded mikrokontroléry.

Rust Memory Safety / Sys

Garantuje bezpečnost paměti bez Garbage Collectoru díky konceptu vlastnictví (Borrow checker). Nahrazuje C++ v jádru Linuxu.

Go (Golang) Cloud / Mikroslužby

Jednoduchá syntaxe od Googlu navržená pro masivní konkurentní sítě (Goroutines). Napsán v něm Docker i Kubernetes.

Kotlin & Swift Mobilní aplikace / Nativní

Moderní typově bezpečné jazyky s elegantní syntaxí pro smartphony. Kotlin vládne nativnímu Androidu, Swift je standardem pro iOS a Apple ekosystém.

Přímé srovnání syntaxe: Stejná úloha v 6 jazycích

Podmínka a cyklus vypisující sudá čísla od 1 do 10 – sledujte odlišnosti v zápisu proměnných, bloků a výstupu.

Python (Odsazení namísto složených závorek) .py 
# Čistý zápis bez středníků
for number in range(1, 11):
    if number % 2 == 0:
        print(f"Sude: {number}")
JavaScript (C-style syntaxe, složené závorky) .js 
// Bloky vymezeny { } a středníky
for (let number = 1; number <= 10; number++) {
  if (number % 2 === 0) {
    console.log(`Sude: ${number}`);
  }
}
PHP (Prefix $ u proměnných, echo a interpolace) .php 
// Proměnné vždy začínají znakem $ a výstup echo
for ($number = 1; $number <= 10; $number++) {
    if ($number % 2 === 0) {
        echo "Sude: $number\n";
    }
}
C++ (Statické typy, přímé I/O streamy) .cpp 
#include <iostream>
int main() {
    for (int number = 1; number <= 10; ++number) {
        if (number % 2 == 0) {
            std::cout << "Sude: " << number << "\n";
        }
    }
    return 0;
}
C# (.NET, objektový obal a jmenný prostor) .cs 
// .NET, interpolovaný řetězec $""
for (int number = 1; number <= 10; number++) {
    if (number % 2 == 0) {
        Console.WriteLine($"Sude: {number}");
    }
}
Ruby (Objektový rozsah, blok do..end, postfix if) .rb 
# Výrazová elegance bez závorek a středníků
(1..10).each do |number|
  puts "Sude: #{number}" if number.even?
end

Jak zvolit správný jazyk pro konkrétní úlohu?

Profesionální programátor se neptá „co je nejlepší“, ale „co nejlépe vyhovuje zadání“.

Klíčová kritéria pro rozhodování

  • Cílová platforma: Prohlížeč vyžaduje JS/TS; mikrokontrolér STM32 vyžaduje C/C++; iOS vyžaduje Swift.
  • Nároky na výkon a paměť: Herní grafický engine potřebuje C++/Rust; webový dashboard zvládne Python nebo Node.js.
  • Rychlost dodání (Time to Market): Skriptovací jazyky umožňují vytvořit funkční prototyp za hodiny.
  • Typová bezpečnost: U velkých týmů se stovkami tisíc řádků kódu chrání statické typy (TS, C#, Java) před hloupými překlepy.

Odlehčení pro pobavení: Exotické & ezoterické jazyky (Esolangs)

Programování nemusí být jen seriózní inženýrství. Vývojáři stvořili desítky bizarních jazyků pro recesi, umění i zkoumání limitů algoritmizace.

Brainfuck

Minimalismus

Vytvořen v roce 1993 s cílem mít co nejmenší možný překladač (měl 240 bajtů). Obsahuje pouze 8 znaků: > < + - . , [ ] pro posun na pásce bajtů.

// Program "Hello World!":
++++++++[>++++[>++>+++>+++>+<<<<-]>+>+>->>+[<]<-]>>.>---.+++++++..+++.>>.<-.<.+++.------.--------.>>+.>++.

Rockstar

Rocková balada

Kód je navržen tak, aby se četl jako text heavymetalové balady z 80. let. Délka slov určuje čísla (poetické literály), proměnné jsou postavy a operace jsou rockové verše.

// Skutečný spustitelný kód:
Midnight takes your heart
While your heart is high
  Put your heart into fire
Give back your heart

Whitespace

Neviditelný kód

Ignoruje veškeré viditelné znaky (písmena i čísla). Instrukcemi jsou výhradně mezery (Space), tabulátory (Tab) a odřádkování (LF). Kód lze skrýt do jiného souboru!

// Prohlížeč vidí prázdno:
[Space][Space][Space][Tab]
[Tab][LF][Space][Space]
[Tab][LF][Tab][Space]
(Na obrazovce 100% neviditelný)

Piet

Abstraktní obraz

Pojmenován po malíři Pietu Mondrianovi. Kódem není text, ale bitmapový obrázek (PNG) s 20 barvami. Instrukce jsou definovány přechody odstínů a jasu mezi sousedními pixely.

// Grafická mozaika pixelů:
Instrukce = Δ Odstín + Δ Jas
Ukazatel bloudí po plátně.
Kód vypadá jako obraz na zeď!
Proč ezoterické jazyky existují? Slouží v teoretické informatice k výzkumu syntaktické analýzy (parserů) a limitů Turingovy úplnosti. Mezi další slavné patří Chef (kód maskovaný za recept na čokoládový dort), Befunge (2D kód čtený všemi směry) či Shakespeare (kód jako divadelní hra).

Shrnutí tématu & Kontrolní otázky

Ověřte si porozumění typovým systémům, kompilaci a paradigmatům.

Shrnutí klíčových bodů:

Programovací jazyky se dělí podle abstrakce (nízko vs. vysokoúrovňové), způsobu překladu (kompilace vs. interpretace vs. JIT bytecode) a typového systému (statické vs. dynamické, silné vs. slabé). Žádný jazyk není univerzálně nejlepší; každý je optimalizován pro jinou doménu.

1. Jaký je rozdíl mezi staticky a dynamicky typovaným jazykem?
Ve staticky typovaném jazyce (C#, Java, C++) se typy proměnných ověřují v době překladu (kompilace). V dynamicky typovaném jazyce (Python, JS) se typ proměnné váže na hodnotu a kontroluje se až za běhu programu.
2. Co znamená, když má jazyk Just-In-Time (JIT) kompilátor?
Zdrojový kód je přeložen do mezikódu (bytecode). Virtuální stroj během běhu analyzuje často volané části programu a za běhu (Just In Time) je zkompiluje do nativního strojového kódu CPU pro dosažení vysokého výkonu.
3. Proč JavaScript vyhodnotí výraz "5" + 2 jako "52", ale Python vyvolá chybu?
JavaScript má slabý typový systém a provede implicitní přetypování (číslo 2 převede na řetězec a spojí je). Python je silně typovaný jazyk a odmítne sčítat číslo s textovým řetězcem bez explicitní konverze str() nebo int().
4. K čemu slouží balíčkovací manažery jako npm, pip nebo NuGet?
Umožňují vývojářům snadno instalovat, sdílet a spravovat knihovny a moduly třetích stran, včetně řešení jejich vzájemných verzí a závislostí.
