Základní konstrukce třídy ve 3 jazycích

Klíčové slovo class, tělo třídy a vytvoření první živé instance v paměti.

Jak jazyky definují třídu?

Všechny tři moderní jazyky používají klíčové slovo class a konvenci PascalCase (např. UserProfile, BankAccount).

Instanciace: Zrození objektu

  • Python: Volá se přímo název třídy jako funkce: u = User().
  • JavaScript & PHP: Vyžadují operátor new: const u = new User(); resp. $u = new User();.
Častá chyba v JS/PHP: Vynechání "new"

V JavaScriptu vyvolá volání User() bez new chybu TypeError: Class constructor cannot be invoked without 'new'.

První třída
# 1. Definice prázdné třídy class Hrac: pass # 2. Vytvoření instance (voláním třídy) hrac1 = Hrac() hrac2 = Hrac() print(type(hrac1)) # <class '__main__.Hrac'> print(hrac1 == hrac2) # False (jsou to dvě různé instance!)
// 1. Definice prázdné třídy class Hrac { // tělo třídy } // 2. Vytvoření instance operátorem 'new' const hrac1 = new Hrac(); const hrac2 = new Hrac(); console.log(hrac1 instanceof Hrac); // true console.log(hrac1 === hrac2); // false (různé adresy)
// 1. Definice prázdné třídy class Hrac { // tělo třídy } // 2. Vytvoření instance operátorem 'new' $hrac1 = new Hrac(); $hrac2 = new Hrac(); var_dump($hrac1 instanceof Hrac); // bool(true) var_dump($hrac1 === $hrac2); // bool(false)

Členy třídy: Datový stav & Ukazatel na instanci

Jak objekt přistupuje ke svým vlastním datům pomocí self, this a $this.

Metoda je funkce svázaná s třídou. Aby metoda věděla, se kterým konkrétním objektem právě pracuje, dostává odkaz na aktuální instanci:

Python: self Explicitní 1. parametr každé metody
JavaScript: this Implicitní kontext volání metody
PHP: $this Automatická pseudo-proměnná
Typická chyba v Pythonu

Napsat def pozdrav(): místo def pozdrav(self): způsobí při volání obj.pozdrav() chybu: takes 0 positional arguments but 1 was given.

self / this v akci
class Hrac: def nastav_jmeno(self, jmeno): self.jmeno = jmeno # Atribut instance def pozdrav(self): # Čtení vlastního stavu přes self return f"Ahoj, já jsem {self.jmeno}!" h = Hrac() h.nastav_jmeno("Karel") print(h.pozdrav())
class Hrac { nastavJmeno(jmeno) { this.jmeno = jmeno; // Přiřazení instanci } pozdrav() { // Přístup k instančnímu atributu return `Ahoj, já jsem ${this.jmeno}!`; } } const h = new Hrac(); h.nastavJmeno("Karel"); console.log(h.pozdrav());
class Hrac { public string $jmeno; public function nastavJmeno(string $jmeno): void { $this->jmeno = $jmeno; } public function pozdrav(): string { return "Ahoj, já jsem " . $this->jmeno . "!"; } } $h = new Hrac(); $h->nastavJmeno("Karel"); echo $h->pozdrav();

Konstruktor: Zrození a inicializace instance

Speciální metoda, která se automaticky spustí při vytváření objektu a zajistí jeho platný počáteční stav.

K čemu slouží konstruktor?

Bez konstruktoru by mohl vzniknout objekt v neúplném stavu (např. uživatel bez jména a e-mailu). Konstruktor vynutí předání povinných údajů a rovnou je zvaliduje.

Názvy konstruktoru v jazycích:

  • Python: def __init__(self, ...) (tzv. dunder metoda).
  • JavaScript: constructor(...) uvnitř těla třídy.
  • PHP: public function __construct(...). V PHP 8+ podporuje tzv. Constructor Property Promotion (přímou deklaraci atributů v parametrech).
Konstruktor
class Produkt: def __init__(self, nazev, cena, na_sklade=0): if cena < 0: raise ValueError("Cena nesmí být záporná!") self.nazev = nazev self.cena = cena self.na_sklade = na_sklade # Vytvoření s validací p1 = Produkt("Myš", 499.0, 10) # p2 = Produkt("Klávesnice", -100) -> Vyvolá ValueError!
class Produkt { constructor(nazev, cena, naSklade = 0) { if (cena < 0) { throw new Error("Cena nesmí být záporná!"); } this.nazev = nazev; this.cena = cena; this.naSklade = naSklade; } } const p1 = new Produkt("Myš", 499.0, 10);
class Produkt { // PHP 8 Constructor Promotion (šetří kód) public function __construct( public string $nazev, public float $cena, public int $naSklade = 0 ) { if ($cena < 0) { throw new InvalidArgumentException("Záporná cena!"); } } } $p1 = new Produkt("Myš", 499.0, 10);

Životní cyklus objektu: Paměť a Garbage Collector

Jak počítač spravuje objekty na haldě (Heap) a jak uvolňuje paměť po jejich zániku.

Zásobník (Stack) vs. Halda (Heap)

Proměnná (např. u1) leží na rychlém zásobníku, ale neobsahuje celý objekt! Obsahuje pouze paměťovou referenci (ukazatel) na dynamicky přidělený prostor na haldě (Heap), kde žijí reálná data objektu.

Garbage Collection (Automatický úklid)

Když na objekt na haldě přestane odkazovat jakákoli proměnná (počet referencí klesne na 0), objekt se stává nedosažitelným a Garbage Collector (GC) jeho paměť automaticky vrátí operačnímu systému.

Destruktory: Python nabízí __del__ a PHP __destruct pro uzavření souborů či databázových spojení před smazáním objektu. V JavaScriptu se destruktory nepoužívají.

Řízení přístupu: Public, Private a Protected

Proč a jak zamykat vnitřní stav třídy před neoprávněným přímým zápisem.

1. Public (Veřejný)

Přístupný z libovolného místa v programu. Typicky se používá pro metody tvořící veřejné API objektu.

2. Private (Soukromý)

Přístupný výhradně uvnitř těla dané třídy. Vnější kód ani odvozený potomek k němu nemá přímý přístup.

3. Protected (Chráněný)

Přístupný ve třídě a ve všech jejích dědických potomcích, ale nepřístupný pro okolní svět.

Viditelnost
class Bankomat: def __init__(self): self.lokace = "Praha" # Public self._servisni_pin = 1234 # Protected (konvence _) self.__trezor = 500000 # Private (name mangling __) def vyber(self, pin, castka): if self.__over_pin(pin): # Volání privátní metody self.__trezor -= castka return castka def __over_pin(self, pin): # Privátní metoda return pin == 9876
class Bankomat { lokace = "Praha"; // Public #trezor = 500000; // Skutečně Private (# znak) vyber(pin, castka) { if (this.#overPin(pin)) { this.#trezor -= castka; return castka; } } #overPin(pin) { // Privátní metoda return pin === 9876; } } const b = new Bankomat(); // b.#trezor -> Způsobí SyntaxError: Private field!
class Bankomat { public string $lokace = "Praha"; protected int $servisniPin = 1234; private float $trezor = 500000; public function vyber($pin, $castka) { if ($this->overPin($pin)) { $this->trezor -= $castka; return $castka; } } private function overPin($pin): bool { return $pin === 9876; } }

Gettery a Settery: Kontrolovaný přístup k datům

Jak číst a měnit skrytý stav elegantně, bezpečně a s automatickou validací pravidel.

Proč nepoužívat veřejné proměnné?

Pokud napíšete student.vek = -25, bez getteru/setteru systém nezasáhne a uloží nesmysl. Setter zajistí, že záporný věk bude okamžitě odmítnut. Getter může hodnotu před vrácením zformátovat (např. jméno s velkým písmenem).

Syntaxe v jazycích:

  • Python: Dekorátory @property (pro čtení) a @vek.setter (pro zápis). Volá se přirozeně jako atribut: s.vek = 18.
  • JavaScript: Klíčová slova get vek() a set vek(v).
  • PHP: Metody getVek() a setVek($v), v PHP 8.4 také nativní property hooks.
Gettery & Settery
class Student: def __init__(self, jmeno, vek): self.jmeno = jmeno self.vek = vek # Použije setter níže! @property def vek(self): return self._vek @vek.setter def vek(self, hodnota): if hodnota < 0 or hodnota > 120: raise ValueError("Neplatný věk studenta!") self._vek = hodnota s = Student("Petr", 17) s.vek = 18 # Volá setter print(s.vek) # Volá getter -> 18
class Student { #vek; constructor(jmeno, vek) { this.jmeno = jmeno; this.vek = vek; // Aktivuje setter } get vek() { return this.#vek; } set vek(hodnota) { if (hodnota < 0 || hodnota > 120) { throw new RangeError("Neplatný věk!"); } this.#vek = hodnota; } } const s = new Student("Petr", 17); s.vek = 18; // Zápis přes setter
class Student { private int $vek; public function __construct( public string $jmeno, int $vek ) { $this->setVek($vek); } public function getVek(): int { return $this->vek; } public function setVek(int $hodnota): void { if ($hodnota < 0 || $hodnota > 120) { throw new InvalidArgumentException("Neplatný věk!"); } $this->vek = $hodnota; } }

Statické členy: Třída vs. Instance

Kdy data a funkce nepatří jedné konkrétní instanci, ale sdílí je celá třída globálně.

Statický atribut (Static property)

Existuje v paměti pouze jednou pro celou třídu. Změna provedená jednou instancí se projeví pro všechny ostatní. Skvělé například pro počítadlo vytvořených instancí.

Statická metoda (Static method)

Lze ji zavolat bez vytváření instance (např. Math.sqrt(), Kalkulator.secti(5, 3)). Nemá přístup k this / self, protože žádná instance nemusí existovat.

Pozor na zneužití statiky!

Příliš mnoho statických proměnných mění OOP zpět v procedurální kód s globálními proměnnými a znemožňuje psaní jednotkových testů.

Statické členy
class Uzivatel: pocitadlo = 0 # Statický (třídní) atribut def __init__(self, jmeno): self.jmeno = jmeno Uzivatel.pocitadlo += 1 @staticmethod def je_platny_email(email): return "@" in email u1 = Uzivatel("Jan") u2 = Uzivatel("Eva") print(Uzivatel.pocitadlo) # Vytvořeni 2 uživatelé print(Uzivatel.je_platny_email("a@sps.cz"))
class Uzivatel { static pocitadlo = 0; // Statický atribut constructor(jmeno) { this.jmeno = jmeno; Uzivatel.pocitadlo++; } static jePlatnyEmail(email) { return email.includes("@"); } } const u1 = new Uzivatel("Jan"); const u2 = new Uzivatel("Eva"); console.log(Uzivatel.pocitadlo); // 2 console.log(Uzivatel.jePlatnyEmail("a@sps.cz"));
class Uzivatel { public static int $pocitadlo = 0; public function __construct(public string $jmeno) { self::$pocitadlo++; } public static function jePlatnyEmail(string $email): bool { return str_contains($email, "@"); } } $u1 = new Uzivatel("Jan"); $u2 = new Uzivatel("Eva"); echo Uzivatel::$pocitadlo; // 2

Objekty v paměti: Hodnota vs. Reference & Klonování

Proč pouhé přiřazení proměnné nevytvoří nový objekt a jak provést skutečnou nezávislou kopii.

Nebezpečí: b = a zkopíruje pouze odkaz!

Primitivní datové typy (čísla, boolean) se předávají hodnotou (vznikne kopie). Objekty se však vždy předávají referencí. Pokud změníte vlastnost v b, změní se i v a, protože obě proměnné ukazují na stejné místo na haldě!

Řešení: Explicitní klonování objektu
  • Python: Modul copy.copy() (mělká) nebo copy.deepcopy() (hluboká kopie včetně vnořených objektů).
  • JavaScript: Moderní funkce structuredClone(obj) nebo Object.assign({}, obj).
  • PHP: Klíčové slovo clone $obj (spustí magickou metodu __clone).
Klonování vs. Reference
import copy class Bod: def __init__(self, x, y): self.x, self.y = x, y a = Bod(10, 20) b = a # Pouze nová reference! b.x = 999 # Změní i a.x! print(a.x) # Vypíše 999! # Správné vytvoření nezávislé kopie: c = copy.deepcopy(a) c.x = 55 print(a.x) # Zůstává 999 (c je nezávislé)
class Bod { constructor(x, y) { this.x = x; this.y = y; } } const a = new Bod(10, 20); const b = a; // Stejná reference v paměti b.x = 999; console.log(a.x); // 999! // Správné hluboké naklonování: const c = structuredClone(a); c.x = 55; console.log(a.x); // 999 (původní objekt neovlivněn)
class Bod { public function __construct(public int $x, public int $y) {} } $a = new Bod(10, 20); $b = $a; // Stejná reference $b->x = 999; echo $a->x; // 999! // Správné klonování v PHP: $c = clone $a; $c->x = 55; echo $a->x; // Zůstává 999
