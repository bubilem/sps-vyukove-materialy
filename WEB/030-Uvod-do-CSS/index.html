Proč vzniklo CSS a jeho historické poslání

Zásada Separation of Concerns (oddělení zájmů): HTML nese sémantický význam a data, CSS definuje veškerou vizuální podobu.

Temné období webu v 90. letech

V raných verzích HTML neexistoval způsob, jak vizuálně stylovat stránky odděleně. Vývojáři byli nuceni míchat obsah se vzhledem přímo v HTML kódu:

  • Prezentační značky a atributy: Značky jako <font color="red" face="Arial" size="4">, <center>, <big> a <marquee>.
  • Tabulkové layouty: Celé weby byly tvořeny obřími zanořenými tabulkami <table> s neviditelnými transparentními 1px obrázky (spacer GIFy) pro odstup.
  • Neudržitelnost: Změna barvy odkazů nebo fontu v projektu znamenala ruční úpravu stovek HTML souborů napříč celým webem.
  • Datová neefektivita: Každá stránka stahovala tytéž vizuální instrukce znovu a znovu.

Zrod standardu CSS a milníky

V říjnu 1994 navrhl Håkon Wium Lie (ve spolupráci s Timem Berners-Leem v CERNu) koncept Cascading Style Sheets (kaskádových stylů):

1996 – CSS1: První doporučení W3C. Zavedení vlastností pro fonty, barvy, základní zarovnání a okraje.
1998–2011 – CSS2 a CSS2.1: Přidáno absolutní a relativní pozicování, podpora médií pro tisk a sjednocení chování prohlížečů.
2012+ – CSS3 (Modulární architektura): Rozdělení do samostatných modulů (Flexbox, Grid, Animace, Barvy, Média). Specifikace se již neposouvá jako celek, ale vyvíjí se jako živý standard (Living Standard).

Tři způsoby připojení CSS stylů k HTML

Kam se CSS kód zapisuje a proč je externí soubor jednoznačným standardem moderního vývoje.

1. Externí soubor

Doporučený standard

Styly jsou uloženy v samostatném souboru .css a připojeny v hlavičce <head> značkou <link>.

<!-- v <head> v HTML -->
<link rel="stylesheet"
      href="css/style.css">
  • Cachování v prohlížeči: Stáhne se pouze jednou a platí pro celý web.
  • Snadná údržba: Změna jednoho řádku změní vzhled na všech stránkách.
  • Čistota: HTML obsahuje pouze obsah a sémantiku.

2. Interní blok stylů

Jednostránkové weby

Styly jsou zapsány přímo uvnitř značky <style> umístěné v hlavičce <head> daného HTML dokumentu.

<head>
  <style>
    h1 { color: #f97316; }
  </style>
</head>
  • Vhodné pouze pro jednoúčelové samostatné stránky nebo e-mailové šablony (newslettery).
  • Nevýhoda: Nelze sdílet napříč více HTML stránkami, zvětšuje velikost každého HTML dokumentu.

3. Inline styl (v tagu)

Antivzor / Výjimky

Styly zapsané přímo do atributu style="..." konkrétního HTML elementu.

<p style="color: red; font-size: 18px;">
  Text odstavce
</p>
  • Proč se vyvarovat: Porušuje oddělení obsahu a formy, nepřehledný kód, má extrémně vysokou specificitu (těžko se přepisuje).
  • Výjimky: Dynamické pozice generované JavaScriptem (např. pozice myši nebo slideru).

Anatomie pravidla CSS a základní syntaxe

Jak je tvořeno každé pravidlo: Selektor vybere cíl v DOMu, složené závorky ohraničí blok a dvojice vlastnost: hodnota určí vzhled.

Struktura pravidla (Rule set)

h1 {
  color: #f97316;
  font-size: 2rem;
  line-height: 1.3;
}
Selektor (h1): Určuje, které prvky na stránce budou pravidlem formátovány.
Složené závorky { }: Obalují blok všech deklarací pro daný selektor.
Vlastnost (Property): Identifikátor stylu, který chceme měnit (např. color, font-size).
Hodnota (Value): Nastavená hodnota (číslo, barva, klíčové slovo, řetězec).

Pravidla psaní a komentáře v CSS

  • Oddělovač dvojtečka (:) – odděluje název vlastnosti od její přiřazené hodnoty.
  • Ukončovací středník (;) – ukončuje každou jednotlivou deklaraci. Pokud středník vynecháte, prohlížeč celé následující pravidlo zahodí jako neplatné!
  • Nezáleží na bílých znacích: Mezery, tabulátory a konce řádků slouží pouze pro čitelnost vývojářem.
  • Syntaxe komentářů: V CSS se používá pouze blokový víceřádkový komentář /* ... */. Znaky // známé z JS nebo C++ nejsou v čistém CSS platné!
/* Toto je platný komentář v CSS */
.karta {
  padding: 16px; /* vnitřní odstup */
}

Datové typy a hodnoty: Formáty barev v CSS

Od klasických HEX kódů přes RGB a HSL až po moderní barevné prostory s vysokým gamutem OKLCH.

HEX kód

#RRGGBB a #RRGGBBAA

Šestnáctková (hexadecimální) soustava od 00 do FF (0–255) pro složky Red, Green, Blue a volitelnou Alpha průhlednost.

color: #f97316; /* plná barva (6 znaků) */
background: #0f172a80; /* 8 znaků: 80 hex = 50% alfa */
border: #fff; /* zkrácený 3znakový zápis pro #ffffff */
Tradiční, nejrozšířenější zápis pro statické barvy.
RGB & RGBA model

rgb() a rgba(r, g, b, a)

Kanály Red, Green, Blue (0–255 nebo 0–100%) a Alpha kanál pro průhlednost (0.0 = zcela průhledný, 1.0 = plně neprůhledný).

/* Klasický zápis s průhledností RGBA: */
color: rgba(249, 115, 22, 0.75); /* 75% krytí */

/* Moderní sjednocený zápis (lomítko pro alfu): */
color: rgb(249 115 22 / 75%);
Funkce rgba() a rgb() jsou v moderním CSS plně synonymní.
HSL & HSLA model

hsl() a hsla(h, s%, l%, a)

Hue (odstín 0–360° na barevném kruhu), Saturation (sytost 0–100%), Lightness (světlost 0–100%) a volitelná Alpha.

/* Klasický zápis s alfou HSLA: */
background: hsla(24, 95%, 53%, 0.3);

/* Moderní zápis: */
color: hsl(24deg 95% 53% / 30%);
Velmi intuitivní pro vytváření světlejších/tmavších variant odstínu.
Moderní OKLCH & Klíčová slova

oklch(l c h [/ a])

Percepčně rovnoměrný prostor. Umožňuje využít plný gamut displejů Display-P3 (živější a zářivější barvy než staré sRGB).

color: oklch(0.68 0.2 41);
/* Klíčová slova: */
color: currentColor; /* barva děděná z textu */
background: transparent; /* zcela průhledné */
Standard pro moderní barevné palety a design systémy.

Datové typy a hodnoty: Jednotky velikostí v CSS

Absolutní jednotky pro přesné fixní rozměry vs. relativní jednotky pro responzivní a přístupný design.

1. Absolutní jednotky (Fixní měřítka)

px • pt • cm • mm • in

Mají pevně definovanou fyzickou velikost. Neodvíjejí se od okolních prvků ani nastavení uživatele:

px (CSS pixel): Základní vizuální pixel obrazovky (1px = 1/96 palce).
Pozor: Na HiDPI/Retina displejích odpovídá 1 CSS pixel matici 2×2 (4) nebo 3×3 (9) fyzických hardware subpixelů. Vhodný pro tenké rámečky (border: 1px solid #ccc), stíny a fixní ikony.
pt (Typografický bod – Point): Tiskařská jednotka (1pt = 1/72 palce ≈ 1.333px).
Používá se v knižní sazbě a pro tiskové styly (@media print). Na obrazovkách se běžně nepoužívá.
cm & mm & in (Metrické a imperiální míry):
1 in (palec) = 2.54 cm = 96 px • 1 cm = ~37.8 px • 1 mm = ~3.78 px.
K čemu slouží na webu? Pro tiskové šablony (tisk faktur na formát A4: width: 210mm; min-height: 297mm;), štítky na balíky a laboratorní měření. Na monitorech se nepoužívají (každý monitor má jiné rozměry a hustotu DPI).
Proč nepoužívat px pro písmo? Pokud si slabozraký uživatel zvětší výchozí písmo v systému či prohlížeči, text zadaný v px se nezvětší (bariéra v přístupnosti a11y).

2. Relativní jednotky (Responzivní měřítka)

% • rem • em • vw • vh • dvh • ch

Dynamicky se přizpůsobují nadřazenému kontextu, kořenovému písmu nebo oknu prohlížeče:

% (Procenta – Vztah k rodiči):
Počítá se vždy z velikosti rodičovského elementu. U width: 50% zabere polovinu šířky rodiče. Klíčové pro responzivní sloupce a fluidní obrázky (max-width: 100%).
rem (Root EM – Zlatý standard textu):
Relativní k písmu kořene <html> (výchozí 16px).
1rem = 16px • 1.5rem = 24px • 2rem = 32px • 0.875rem = 14px.
Při zvětšení písma uživatelem se celý web proporcionálně přizpůsobí.
em (Element EM): Relativní k písmu aktuálního elementu či rodiče.
Skvělé pro vnitřní okraje tlačítek (padding: 0.6em 1.2em se zvětší spolu s písmem tlačítka). Pozor na násobení u zanořených seznamů!
vw / vh & moderní dvh (Viewport):
1vw = 1 % šířky okna • 1vh = 1 % výšky okna.
dvh (Dynamic Viewport Height): Řeší problém na mobilních telefonech – výška se dynamicky přizpůsobuje vysouvání a skrývání adresního řádku prohlížeče.
ch (Character width): Šířka číslice 0 v daném fontu.
Ideální pro optimální délku řádku textu pro lidské oko: max-width: 65ch;.

CSS Box Model – Principy a anatomie 4 vrstev

Každý element vykreslený prohlížečem je obdélníková krabička tvořená čtyřmi soustřednými vrstvami.

MARGIN (Vnější okraj)
BORDER (Rámeček)
PADDING (Vnitřní odstup)
CONTENT (Obsah: Text, Obrázek, Dětské prvky)

4 vrstvy od středu ven

  • 1. Content (Obsah): Skutečný obsah elementu (text, video, obrázek). Definují ho vlastnosti width a height.
  • 2. Padding (Vnitřní okraj): Prostor mezi obsahem a rámečkem. Prosvítá jím pozadí elementu (background).
  • 3. Border (Rámeček): Hrana obepínající obsah a padding. Lze nastavit tloušťku, styl (solid, dashed...) a barvu.
  • 4. Margin (Vnější okraj): Prázdný odstup oddělující tento prvek od okolních prvků v layoutu. Je zcela průhledný.
  • Margin collapsing: Pokud se nad sebou potkají dva vertikální okraje (např. spodní margin 20px a horní margin 30px), nesčítají se na 50px, ale splynou do většího z nich (výsledek bude 30px).

Klíčová vlastnost: box-sizing

Zásadní rozdíl mezi historickým výchozím výpočtem a moderním standardem, který používá každý webový vývojář.

Výchozí chování (historické)

box-sizing: content-box;

Zadaná hodnota width a height určuje pouze samotný obsah (content). Padding a border se k zadané šířce přičítají!

.box {
  box-sizing: content-box;
  width: 200px;
  padding: 20px;
  border: 5px solid red;
}
/* Skutečná šířka v prohlížeči:
   200 + (2 × 20) + (2 × 5) = 250px ! */

Důsledek: Pokud nastavíte dvěma sloupcům width: 50% a přidáte jim padding, nevejdou se vedle sebe a zalomí se pod sebe.

Moderní doporučený standard

box-sizing: border-box;

Zadaná hodnota width a height je konečná celková velikost. Padding a border se odečítají zevnitř, obsah se přizpůsobí!

.box {
  box-sizing: border-box;
  width: 200px;
  padding: 20px;
  border: 5px solid red;
}
/* Skutečná šířka v prohlížeči:
   Přesně 200px (šířka obsahu se zúží na 150px) */
Zlaté pravidlo moderního CSS (globální reset):
*, *::before, *::after { box-sizing: border-box; }

Souhrn a osvědčené postupy pro žáky SPŠ

Stručný přehled fundamentálních principů pro efektivní a bezchybnou práci s kaskádovými styly.

1. Architektura souborů

  • Vždy používejte externí soubory .css připojené v <head>.
  • Vyhněte se inline stylům (style="...") v HTML.
  • Oddělujte obsah (HTML) od prezentace (CSS).

2. Zlaté pravidlo Box modelu

  • Vždy na začátek každého CSS souboru vložte reset:
    *, *::before, *::after { box-sizing: border-box; }
  • Šířka a výška prvků pak zůstane předvídatelná a layout se nerozsype při přidání paddingu.

3. Volba správných jednotek

  • rem: Pro písmo (font-size) a typografické rozestupy.
  • px: Pro drobné rámečky (border) a jemné stíny.
  • % / vw / vh: Pro responzivní šířky sloupců a layoutové mřížky.

Ověření znalostí: Kontrolní otázky

Otestujte si pochopení základů CSS a Box modelu. Kliknutím na tlačítko si ověříte správnou odpověď.

1

Element má nastaveno width: 300px; padding: 20px; border: 5px solid red; bez uvedení box-sizing. Jaká bude jeho skutečná šířka na obrazovce a proč?

Jeho skutečná šířka bude 350px. Ve výchozím nastavení platí box-sizing: content-box, kde zadaná šířka 300px platí pouze pro obsah. K němu se přičte levý a pravý padding (2 × 20px = 40px) a levý a pravý border (2 × 5px = 10px). Výsledek: 300 + 40 + 10 = 350px.
2

Proč se v moderním webdesignu pro velikost písma upřednostňuje jednotka rem před absolutními pixely px?

Z důvodu přístupnosti (accessibility / a11y). Jednotka rem vychází z kořenového písma elementu <html>. Pokud si uživatel se zrakovým postižením zvětší výchozí písmo v nastavení svého prohlížeče (např. z 16px na 24px), veškeré texty v jednotkách rem se plynule a proporčně zvětší. Fixní px toto nastavení ignorují.
3

Co přesně znamená jev „margin collapsing“ (slučování vnějších okrajů) a kdy k němu dochází?

K margin collapsing dochází, když se ve svislém toku dokumentu potkají dva vertikální vnější okraje (např. margin-bottom horního odstavce a margin-top spodního odstavce). Tyto dva okraje se nesčítají, ale splynou v jeden jediný okraj, jehož velikost odpovídá té větší z obou hodnot. U vodorovných okrajů k tomuto jevu nikdy nedochází.
4

Jaký je rozdíl mezi interním zápisem stylů v <style> a externím souborem .css z hlediska výkonu prohlížeče?

Externí soubor .css prohlížeč stáhne ze sítě pouze jednou a následně jej uloží do diskové vyrovnávací paměti (HTTP cache). Při přechodu na další podstránky webu se styly již nestahují. Naproti tomu interní <style> blok je pevnou součástí HTML kódu, takže se zbytečně přenáší po síti a parsuje s každou jednotlivou navštívenou stránkou.
