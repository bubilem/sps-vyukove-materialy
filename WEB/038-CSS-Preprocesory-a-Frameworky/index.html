Co je to CSS Preprocesor a princip kompilace

Proč čisté CSS v minulosti vývojářům nestačilo a jak funguje překlad do standardního CSS.

Princip kompilace

Webový prohlížeč rozumí výhradně čistému CSS. Nerozumí souborům .scss ani .less.

Zdrojový SCSS kód → Překladač (Sass/Node.js) → Výsledné standardní CSS
  • Sass (SCSS): Dnes celosvětový standard mezi preprocesory.
  • Less: Dříve populární (používal jej starý Bootstrap).
  • Stylus: Alternativní preprocesor bez závorek a středníků.

Hlavní výhody SCSS

  • Syntaktická nadmnožina: Každý platný CSS kód je zároveň platným SCSS kódem.
  • Proměnné se znakem dolaru: $primary: #38bdf8;.
  • Mixiny: Znovupoužitelné šablony kódu jako funkce s parametry.
  • Matematické operace: Přirozené počítání rozměrů přímo při kompilaci.

Základní syntaxe SCSS: Proměnné a Nesting

Jak SCSS zkracuje zápis a umožňuje logicky strukturovat kód do vnořených bloků.

Zdrojový soubor: style.scss 
// SCSS proměnné
$primary: #38bdf8;
$radius: 8px;

.card {
  border-radius: $radius;

  h3 {
    color: $primary;
  }

  &:hover {
    box-shadow: 0 4px 12px rgba($primary, 0.25);
  }
}
Zkompilovaný výstup: style.css 
.card {
  border-radius: 8px;
}

.card h3 {
  color: #38bdf8;
}

.card:hover {
  box-shadow: 0 4px 12px rgba(56, 189, 248, 0.25);
}

Překladač automaticky rozbalil selektory a dosadil statické hodnoty barev a rozměrů.

Znovupoužitelné šablony: @mixin a @include

Vytvořte si vlastní knihovnu opakujících se vzorů (Flexbox zarovnání, ořezání textu s trojtečkou).

Definice mixinu s parametry 
// Mixin pro dokonalé flex centrování
@mixin center-flex($direction: row) {
  display: flex;
  flex-direction: $direction;
  justify-content: center;
  align-items: center;
}

// Mixin pro jednořádkový text s trojtečkou (...)
@mixin truncate-text {
  overflow: hidden;
  text-overflow: ellipsis;
  white-space: nowrap;
}
Volání pomocí @include 
.hero-banner {
  @include center-flex; // Výchozí row
  min-height: 400px;
}

.user-name {
  @include truncate-text;
  max-width: 150px;
}

Mixiny zásadně snižují duplikaci kódu a udržují jednotný styl napříč projektem.

Metodika BEM: Block, Element, Modifier

Světoznámý standard pro pojmenovávání tříd, který zabraňuje kolizím a chaosu ve velkých projektech.

Tři pilíře BEM
  • Block (Blok): Samostatná znovupoužitelná komponenta (např. .card, .navbar, .btn).
  • Element (Prvek): Část bloku oddělená dvěma podtržítky __ (např. .card__title, .card__body, .card__btn).
  • Modifier (Modifikátor): Varianta či stav oddělený dvěma pomlčkami -- (např. .card--featured, .btn--danger).
BEM + SCSS = Dokonalá souhra 
.card {
  background: #1e293b;

  &__title { /* Vytvoří .card__title */
    font-size: 1.25rem;
  }

  &--featured { /* Vytvoří .card--featured */
    border: 2px solid #f97316;
  }
}

Komponentové frameworky: Fenomén Bootstrap

Předpřipravené knihovny hotových komponent pro bleskurychlý vývoj firemních aplikací.

Co Bootstrap přináší?

  • Hotové UI komponenty: Modální okna, rozevírací menu (dropdown), akordeony, navigační lišty, alerty.
  • 12sloupcový Grid systém: Třídy jako .row, .col-md-6, .col-lg-4.
  • Rychlost: Funkční prototyp webu složíte za desítky minut pouhým kopírováním HTML kousků.

Nevýhody komponentových frameworků

  • Generický vzhled: Všechny weby postavené na Bootstrapu vypadají zpočátku stejně („bootstrapový vzhled“).
  • Obtížné přizpůsobení: Přepsání výchozích stylů často vede k boji s kaskádou a specifitou.
  • Datová zátěž: Pokud nepoužijete modulární build, stahujete stovky kilobajtů nepoužitého kódu.

Revoluce jménem Tailwind CSS (Utility-First)

Zcela nová filozofie: místo psaní vlastních CSS selektorů skládáte vzhled z atomických tříd přímo v HTML.

Jak vypadá HTML v Tailwindu? 
<div class="flex items-center justify-between p-4 bg-slate-900 rounded-lg shadow-lg hover:bg-slate-800 transition">
  <h3 class="text-lg font-bold text-sky-400">
    Moderní karta
  </h3>
  <button class="px-4 py-2 bg-indigo-600 rounded text-white">
    Akce
  </button>
</div>
Proč vývojáři Tailwind milují?
  • Nepřemýšlíte nad názvy tříd: Už žádné vymýšlení, zda to nazvat .card-inner-wrap nebo .card-box-holder.
  • Žádný mrtvý kód: Překladač (JIT) vygeneruje přesně jen ty třídy, které jste v HTML skutečně použili. Výsledný CSS soubor má často méně než 15 kB!
  • Responzivita a stavy přímo v třídě: Např. md:flex nebo hover:text-white.

Kdy zvolit který přístup: Čisté CSS vs. SCSS vs. Tailwind

Objektivní porovnání technologií pro různé typy webových zakázek.

Přístup Čisté moderní CSS SCSS (Sass) Tailwind CSS
Nutnost kompilace Žádná (běží 100% nativně). Nutný překladač (Node.js/Dart). Nutný build nástroj (PostCSS/Vite).
Filozofie Sémantické třídy a webové standardy. Modulární BEM komponenty, mixiny. Utility-first atomické třídy v HTML.
Ideální pro Menší až střední weby, výuku základů, nulové závislosti. Velké design systémy, komplexní enterprise portály. Moderní webové aplikace v Reactu, Vue, Next.js.

Build nástroje: PostCSS, Autoprefixer a minifikace

Jak moderní nástroje připravují styly pro produkční nasazení na server.

PostCSS & Autoprefixer

PostCSS: Nástroj pro transformaci CSS pomocí pluginů v JavaScriptu.
Autoprefixer: Plugin, který na základě databáze Can I Use automaticky doplňuje vendor prefixy (např. -webkit-) pro starší prohlížeče. 

/* V kódu napíšete: */
user-select: none;

/* Autoprefixer sám vygeneruje pro produkci: */
-webkit-user-select: none;
-moz-user-select: none;
user-select: none;
Minifikace CSS pro produkci

Během buildu (např. ve Vite nebo esbuild) se odstraní veškeré komentáře, mezery a odřádkování. 

.card{background:#1e293b;border-radius:8px;padding:1.5rem}

Zmenší objem přenášených dat po síti o 40–70 % a zrychlí načítání pro uživatele na mobilech.

Případová studie: Od špagetového CSS k čistému BEM

          
Jak ze starého, neudržitelného kódu vytvořit přehlednou modulární komponentu.

        

        

          

            

              Před refaktoringem (Křehký kód)
              
/* Nebezpečné generické selektory: */
.box { padding: 20px; }
.box div { font-weight: bold; }
.box span { color: gray; }
.box-red { border: 1px solid red; }

              

                Pokud do boxu přidáte jiný <span>, styl se nechtěně rozbije.
              

            


            

              Po refaktoringu do BEM
              
/* Robustní BEM komponenta: */
.article-card { padding: 1.25rem; }
.article-card__title { font-weight: 700; }
.article-card__date { color: #94a3b8; }
.article-card--alert { border: 2px solid #ef4444; }

              

                Každá třída nese přesný význam a má nulovou šanci se srazit s jinou částí webu.
              

            

          

        

      


      
      

        

          
Shrnutí tématu a opakovací otázky

          
Ověřte si své znalosti SCSS, metodiky BEM, Tailwind CSS a produkčních nástrojů.

        

        

          

            
            

              

                01.
                Proč nemůžeme soubor .scss napřímo nalinkovat do HTML značkou <link>?
              

              
              

                Webový prohlížeč neobsahuje překladač jazyka SCSS a rozumí pouze čistému CSS standardu. Soubory SCSS musí nejprve projít fází kompilace (překladu), která vygeneruje běžný soubor .css.
              

            


            
            

              

                02.
                Co znamenají jednotlivá písmena v názvu metodiky BEM a k čemu slouží dvojité podtržítko?
              

              
              

                B = Block (Blok), E = Element (Prvek), M = Modifier (Modifikátor). Dvojité podtržítko (__) odděluje název bloku od jeho vnitřního potomka (např. .card__title), zatímco dvojitá pomlčka (--) označuje variantu nebo stav (např. .card--active).
              

            


            
            

              

                03.
                V čem se liší filozofie frameworku Bootstrap od Tailwind CSS?
              

              
              

                Bootstrap je komponentový framework – nabízí hotové komponenty (tlačítka, modály, navbar) s předem daným designem. Tailwind CSS je utility-first – nabízí drobné stavební kostky (třídy pro barvu, padding, flex), ze kterých si vlastní unikátní design skládáte sami v HTML bez generického vzhledu.
              

            


            
            

              

                04.
                K čemu slouží nástroj Autoprefixer v produkčním buildu?
              

              
              

                Analyzuje hotové CSS a na základě aktuálních statistik podpory prohlížečů (Can I Use) automaticky doplňuje potřebné vendor prefixy (např. -webkit-) pro starší nebo specifické prohlížeče. Vývojář tak nemusí prefixy psát ručně.
