Co je to web? Zásadní rozdíl mezi Internetem a WWW

V běžné řeči se pojmy zaměňují, technicky však představují zcela odlišné vrstvy digitálního světa.

Internet: Fyzická a síťová infrastruktura

Internet je globální soustava navzájem propojených počítačových sítí fungující na sadě protokolů TCP/IP.

  • Hardware a konektivita: Transatlantické podmořské optické kabely, páteřní směrovače (BGP routery), satelity a datacentra.
  • Nezávislost na službě: Poskytuje pouze transportní vrstvu pro přenos paketů mezi IP adresami.
  • Mnoho různých služeb: Nad internetem běží e-mail (SMTP/IMAP), přenos souborů (SFTP), hlasová komunikace (VoIP), herní protokoly, streamování médií i samotný Web.

World Wide Web (WWW): Aplikační hypertextová služba

WWW je jen jedna z mnoha služeb provozovaných na internetu, navržená v roce 1989 Timem Berners-Leem v CERNu.

  • Hypertext a odkazy: Dokumenty navzájem propojené aktivními odkazy (hyperlinks), které umožňují nelineární čtení.
  • Protokol HTTP/HTTPS: Aplikační komunikační protokol pro předávání webových zdrojů.
  • Jednotný identifikátor (URI/URL): Standardizovaný formát adresování jakéhokoli zdroje na planetě.
  • Standardizační autority: W3C (World Wide Web Consortium) a WHATWG (specifikace živého standardu HTML5).

Klient (Webový prohlížeč / Mobilní aplikace)

Zařízení a software koncového uživatele (Chrome, Firefox, Safari, Edge). Odesílá HTTP/HTTPS požadavky a interpretuje přijatý HTML kód, kaskádové styly CSS a spouští JavaScript v izolovaném sandboxu. Klient se stará o vykreslení UI a bezprostřední interakci s uživatelem.

Hardware a software webové infrastruktury

Z čeho se fyzicky skládá serverový svět a jaký software řídí nepřetržitý provoz webu 24/7/365.

Serverový hardware & Datacentra

  • Rackové servery (1U–4U): Speciální štíhlé konstrukce navržené pro standardní 19palcové serverové skříně (racky) s optimalizovaným prouděním vzduchu zepředu dozadu.
  • Redundance komponent: Zdvojené napájecí zdroje (PSU A+B zapojené do nezávislých fází), paměti ECC RAM detekující a opravující bitové chyby, hot-swap NVMe disky v polích RAID.
  • Podmínky datacentra (Tier III/IV): Záložní dieselagregáty (motorgenerátory), obří akumulátory UPS, precizní klimatizace s uličkami teplého a studeného vzduchu, automatické hasicí systémy inertním plynem.
  • Páteřní konektivita: Více nezávislých 100Gbps optických tras od různých telekomunikačních operátorů (multihoming).

Serverový software & Webservery

  • Serverový operační systém: Více než 80 % webových serverů běží na Linuxu (Ubuntu Server, Debian, RHEL, AlmaLinux), menší část na Windows Serveru (IIS).
  • Webové HTTP servery (Démoni):
    • Nginx: Event-driven, asynchronní, bleskový pro statický obsah a reverzní proxy.
    • Apache HTTP Server: Robustní modulární server s podporou .htaccess.
    • Caddy: Moderní server v Go s automatickou správou HTTPS certifikátů Let's Encrypt.
  • Běhová prostředí (Runtimes): Node.js, Python (WSGI/ASGI), PHP-FPM, .NET Kestrel, JVM.
  • Správci procesů: systemd démoni, Docker kontejnery a orchestrace v Kubernetes.

Tři základní pilíře webového vývoje: HTML, CSS a JavaScript

Každá webová stránka je ve svém jádru tvořena dokonalou symbiózou struktury, vizuálu a interaktivity.

HTML5: Sémantická kostra

HyperText Markup Language: Definuje význam a strukturu informací na stránce.

  • Sémantické značky (<header>, <nav>, <article>, <footer>).
  • Dává obsahu hierarchii (nadpisy h1–h6, odstavce, tabulky, seznamy).
  • Nese metadata pro vyhledávače a sociální sítě.
  • Klíčový pro čtečky obrazovky a přístupnost.

CSS3: Vizuální podoba & Styl

Cascading Style Sheets: Řídí estetickou prezentaci a rozvržení prvků na různých obrazovkách.

  • Responzivní design (Media queries, Fluidní layout).
  • Moderní layoutové systémy Flexbox a CSS Grid.
  • Barvy, typografie, stíny, glassmorphism a adaptace na tmavý režim.
  • Plynulé animace a CSS transformace akcelerované GPU.

JavaScript: Mozek & Chování

Programovací jazyk ECMAScript: Vdechuje stránce dynamický život a interaktivitu.

  • Manipulace s Document Object Modelem (dynamické úpravy DOM bez reloadu).
  • Reakce na události uživatele (kliknutí, klávesnice, scroll).
  • Asynchronní stahování dat na pozadí pomocí fetch() a AJAX.
  • Moderní frontendové frameworky (React, Vue, Svelte, Angular).

Čtvrtý nastupující pilíř: WebAssembly (Wasm)

Binární instrukční formát navržený pro běh kódu psaného v C++, Rustu nebo Go přímo v prohlížeči téměř nativní rychlostí procesoru. Využívá se pro náročné grafické editory (Figma), 3D hry, video střižny a vědecké simulace.

Přínosy, technologické výzvy a bezpečnostní rizika

Proč se web stal dominantní aplikační platformou světa a s jakými úskalími musí webový vývojář počítat.

Hlavní přínosy webových technologií

  • Okamžitý přístup bez instalace: Uživatel otevře odkaz a má k dispozici plnohodnotný software bez stahování instalátorů a zabírání místa na disku.
  • Univerzální multiplatformnost: Jeden kód běží na Windows, macOS, Linuxu, Androidu i iOS uvnitř standardizovaného prohlížeče.
  • Průběžné aktualizace: Opravy chyb a nové funkce se nasadí na server a okamžitě jsou dostupné všem uživatelům světa najednou.
  • PWA (Progresivní webové aplikace): Schopnost běžet offline, instalovat se na plochu telefonu a odesílat push notifikace.

Úskalí, limity a bezpečnostní rizika

  • Bezpečnostní vektory útoků: XSS (Cross-Site Scripting), CSRF podvržení požadavku, SQL Injection a Man-in-the-Middle odposlechy nezašifrované komunikace.
  • Závislost na síťovém spojení: Bez stabilního internetu je většina tradičních webových aplikací zcela paralyzována.
  • Masivní profilování a ochrana soukromí: Sledovací cookies, digitální otisk zařízení (browser fingerprinting) a legislativní regulace (GDPR, ePrivacy).
  • Fragmentace a výkon: Rozdíly mezi verzemi prohlížečů, paměťová náročnost JavaScriptových SPA aplikací a pomalé načítání na mobilních sítích.

Zopakujte si klíčové koncepty úvodu do webových technologií před přechodem na webovou komunikaci.

Internet vs. WWW

Internet je síťová transportní infrastruktura TCP/IP, Web je hypertextová aplikační služba navržená Timem Berners-Leem.

Klient • Proxy • Backend

Prohlížeč žádá data, CDN cachuje, reverzní proxy balancuje provoz a backend s databází generuje aplikační data.

DNS • Standardy • a11y

DNS hierarchicky překládá domény na IP adresy. Standardy WCAG zajišťují přístupnost pro všechny uživatele bez rozdílu.

1

Jaký je hlavní rozdíl mezi internetem a službou World Wide Web?

Internet je globální síťová infrastruktura propojující hardware a zajišťující přenos paketů (TCP/IP). WWW (Web) je pouze jednou z mnoha aplikačních služeb provozovaných nad internetem, založenou na přenosu hypertextových dokumentů a multimédií přes HTTP/HTTPS.
2

K čemu v moderní architektuře slouží reverzní proxy (např. Nginx) a proč se klienti nepřipojují přímo na aplikační server?

Reverzní proxy funguje jako bezpečnostní a výkonnostní štít. Provádí terminaci SSL/TLS šifrování, rozložení zátěže (Load Balancing) mezi více backendových serverů, cachuje statické odpovědi a chrání citlivý backend s databází před přímým přístupem z veřejného internetu.
3

Proč pouhé obarvení textu nestačí k zajištění dobré přístupnosti (a11y) a jaké je základní pravidlo pro tlačítka?

Barvoslepí či slabozrací uživatelé nemusí barevný rozdíl vnímat, proto musí mít text vysoký kontrastní poměr (dle WCAG minimálně 4.5:1) a informace nesmí stát pouze na barvě. Tlačítka musí být tvořena sémantickou značkou <button> (nikoli pouhým divem), aby byla dostupná z klávesnice přes klávesu Tab a čtečky obrazovky poznaly její interaktivní účel.
4

Jaký je rozdíl mezi DNS záznamy typu A, CNAME a MX?

Záznam A mapuje doménové jméno přímo na IPv4 adresu serveru (např. skolavdf.cz ➔ 81.2.195.118). Záznam CNAME vytváří alias odkazující na jiné doménové jméno (např. www.skolavdf.cz ➔ skolavdf.cz). Záznam MX definuje poštovní servery určené pro příjem e-mailových zpráv pro danou doménu.
