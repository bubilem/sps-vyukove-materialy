CSS selektory a pseudotřídy

Cílení na elementy DOM stromu s chirurgickou přesností • Od základních značek a tříd přes kombinátory potomků a sourozenců, atributové filtry, dynamické a strukturální pseudotřídy, virtuální pseudoelementy (rozdíl : vs ::) až po matematický výpočet specificity.

Základní selektory

Univerzální *, typový tag, třída .class, unikátní ID #id a seskupování čárkou.

Kombinátory v DOM

Potomek (mezera), přímé dítě (>), sousední sourozenec (+) a obecný bratr (~).

Pseudotřídy a prvky

Stavy :hover, :focus, :nth-child(), logické :not() a virtuální prvky ::before / ::after.

Specificita & Kaskáda

4složkový vektor vah, řešení konfliktů a bezpečné techniky bez nutnosti !important.

Role selektoru a základní stavební kameny

Selektor říká prohlížeči, které uzly v DOM stromu mají převzít daná stylová pravidla.

Čtyři elementární typy výběru

  • 1. Univerzální selektor (*): Cílí na naprosto všechny elementy v dokumentu. Typicky se používá pro globální reset box-modelu. 
    * { margin: 0; box-sizing: border-box; }
  • 2. Typový selektor (Tag): Cílí na všechny prvky daného HTML tagu (např. p, h1, button). 
    p { line-height: 1.6; }
  • 3. Třída (Class .nazev): Základní stavební kámen znovupoužitelného designu. Může být přiřazena libovolnému množství elementů. 
    .btn-primary { background: #f97316; }
  • 4. Identifikátor (ID #id): Cílí na jeden unikátní element s daným HTML atributem id="..." na stránce. Má velmi vysokou specificitu, proto se v moderním CSS doporučuje upřednostňovat znovupoužitelné třídy. 
    #hlavni-navigace { background: #0f172a; }

Seskupování selektorů a vyhodnocování

Pokud mají různé elementy sdílet stejná pravidla, seskupujeme je čárkou (,):

/* Seskupení: pravidlo platí pro h1, h2 i h3 */
h1, h2, h3 {
  font-family: 'Inter', sans-serif;
  color: #f8fafc;
}
Jak prohlížeč čte selektory (Zprava doleva):
U komplexních selektorů (např. header nav a.active) prohlížeč nejdříve najde všechny a.active na stránce (Key selector) a teprve poté ověřuje jejich předky směrem nahoru ve stromu.

Kombinátory: Vztahy mezi elementy v DOM stromu

Jak přesně cílit podle rodinných vazeb v DOM: potomci, bezprostřední děti a sousední sourozenci.

Vertikální hierarchie (Rodič • Potomek)

Potomek (Mezera: A B)

Cílí na jakýkoliv element B, který se nachází uvnitř A, bez ohledu na hloubku zanoření.

.card p { color: #94a3b8; }
/* Zacílí odstavec přímo v .card i odstavec uvnitř dalšího divu */

Přímý potomek / Dítě (Zobáček: A > B)

Cílí výhradně na přímé dítě na 1. úrovni zanoření. Ignoruje hlouběji vnořené potomky.

ul > li { list-style: none; }
/* Zacílí pouze li patřící přímo danému ul, ne li ve vnořeném ul */
Horizontální hierarchie (Sourozenci)

Sousední sourozenec (Plus: A + B)

Cílí na element B, který bezprostředně následuje za elementem A a má stejného rodiče.

h2 + p { font-size: 1.2rem; font-weight: 600; }
/* Zacílí pouze první perexový odstavec hned za nadpisem h2 */

Obecný sourozenec (Tilda: A ~ B)

Cílí na všechny elementy B, které následují kdekoliv za elementem A se stejným rodičem.

h2 ~ p { line-height: 1.6; }
/* Zacílí všechny následující odstavce za h2 v dané sekci */

Pokročilé atributové selektory: [atribut]

Filtrování prvků na základě přítomnosti konkrétního HTML atributu nebo jeho textové hodnoty.

Základní shoda

[attr] a [attr="val"]

Cílí na existenci atributu bez ohledu na hodnotu, nebo vyžaduje přesnou absolutní shodu.

/* Všechna deaktivovaná tlačítka: */
button[disabled] {
  opacity: 0.5;
  cursor: not-allowed;
}

/* Pouze textová pole: */
input[type="text"] {
  border: 1px solid #ccc;
}
Prefix a Suffix

[attr^="val"] a [attr$="val"]

Prefixová stříška ^= (začíná na) a suffixový dolar $= (končí na) – ideální pro odkazy a soubory.

/* Všechny zabezpečené externí HTTPS odkazy: */
a[href^="https://"] {
  color: #10b981;
}

/* Odkazy stahující dokumenty PDF: */
a[href$=".pdf"] {
  font-weight: 700;
}
Hledání řetězce

[attr*="val"] a [attr~="val"]

Hvězdička *= matchuje libovolný výskyt podřetězce, tilda ~= celé samostatné slovo.

/* Elementy obsahující v data atributu "admin": */
[data-role*="admin"] {
  border-color: #f43f5e;
}

/* Case-insensitive hledání (příznak i): */
a[href$=".pdf" i] {
  text-decoration: underline;
}

Dynamické a stavové pseudotřídy

Pseudotřída začíná jednou dvojtečkou (:) a cílí na dočasný stav elementu vyvolaný akcí uživatele.

Stavy uživatelské interakce

  • :hover: Kurzor myši se nachází nad elementem. Zásadní pro mikrointerakce a tlačítka.
  • :active: Moment stisknutí tlačítka myši nebo klepnutí na displej (stav kliknutí).
  • :focus: Prvek je aktivní pro vstup (např. fokus v textovém políčku nebo odkaz aktivovaný tabulátorem).
  • :focus-visible (Moderní standard a11y): Zobrazí obrys fokusu pouze při navigaci z klávesnice (klávesa Tab), ale skryje ho při kliknutí myší!
.btn:hover { background: #ea580c; }
.btn:active { transform: scale(0.98); }
.btn:focus-visible { outline: 2px solid #38bdf8; }

Stavy odkazů a pravidlo pořadí LVHA

Při stylování hypertextových odkazů <a> záleží na pořadí v kódu, protože pozdější pravidla přepisují předchozí:

Zlatá mnemotechnická pomůcka: L–V–H–A
  1. :link – dosud nenavštívený odkaz
  2. :visited – dříve navštívený odkaz (historie prohlížeče)
  3. :hover – přejetí kurzorem myši
  4. :active – stisknutí tlačítka myši v okamžiku kliku

Pokud napíšete :hover před :visited, navštívený odkaz by po přejetí myší nezměnil barvu!

Strukturální a stromové pseudotřídy

Cílení na elementy podle jejich přesné pozice a pořadí uvnitř společného rodičovského uzlu.

Pozice v DOM: Kraje a jedinci
  • :first-child: Element, který je úplně prvním potomkem svého rodiče.
  • :last-child: Element, který je posledním potomkem svého rodiče.
  • :only-child: Element, který je jedináčkem (rodič nemá žádné další děti).
  • Rozdíl child vs of-type:
    p:first-child funguje pouze tehdy, je-li <p> skutečně 1. prvkem v rodiči. Pokud je před ním <h1>, nevybere se nic! Naproti tomu p:first-of-type vybere první odstavec bez ohledu na to, zda před ním stojí nadpis.
Magický vzorec :nth-child(An+B)

Umožňuje pruhovat tabulky, vybírat sudé/liché řádky nebo periodicky opakovat styly:

:nth-child(odd) nebo (2n+1) → všechny liché prvky (1, 3, 5, 7...)
:nth-child(even) nebo (2n) → všechny sudé prvky (zebra tabulky)
:nth-child(3n) → každý třetí element (3, 6, 9...)
:nth-child(-n+3) → pouze první 3 elementy (1, 2, 3)

Logické pseudotřídy a revoluční selektor :has()

Moderní selektory pro zkrácení kódu, negaci a výběr rodiče podle stavu potomka.

Logické funkce v CSS

Sdružování a negace: :not, :is a :where

Co je to specificita (váha selektoru)?
Pokud na tentýž prvek míří více různých stylů (např. jeden říká modrá a druhý červená), prohlížeč rozsoudí spor podle specificity – bodové váhy selektoru. Silnější pravidlo vyhraje a slabší přebije.
1. :not(selektor) – Negace:
Vybere všechny elementy, které nesplňují podmínku v závorce. 
/* Všechna tlačítka kromě hlavního: */
button:not(.btn-primary) { opacity: 0.7; }
2. :is(A, B, C) – Zkrácení s nejvyšší vahou:
Místo header a, nav a, footer a napíšeme jednoduše :is(header, nav, footer) a.
Pravidlo váhy: Celý selektor získá specificitu podle nejtěžšího prvku v závorce. Pokud je uvnitř alespoň jedno ID (např. :is(section, #banner) a), má celé pravidlo sílu ID selektoru. 
:is(h1, h2, h3) { line-height: 1.2; } /* Zkrátí zápis pro nadpisy */
3. :where(A, B, C) – Sdružení s NULOVOU vahou (0):
Funguje přesně stejně jako :is(), ale jeho specificita je vždy přesně 0.
K čemu je to dobré? Pro výchozí komponenty a CSS resety. Styl můžete kdekoliv v kódu přepsat jakoukoliv běžnou třídou i samotným tagem bez boje s kaskádou a bez nutnosti používat nebezpečné !important. 
:where(.card, .box) { padding: 1rem; } /* Váha 0 → kdokoliv snadno přepíše */
Svatý grál CSS

:has() – Rodičovský selektor

Dlouhá léta nebylo v CSS možné stylovat rodiče podle toho, co obsahuje. S příchodem :has() se to stalo realitou ve všech moderních prohlížečích:

/* Zvýrazni kartu, POKUD obsahuje odznak s chybou: */
.card:has(.badge-error) {
  border-color: #f43f5e;
  box-shadow: 0 0 12px rgba(244,63,94,0.3);
}

/* Zformátuj popisek formuláře, pokud je políčko neplatné: */
label:has(+ input:invalid) {
  color: red;
}

Pseudoelementy a zásadní rozdíl mezi : a ::

Pseudotřída cílí na stav reálného prvku, pseudoelement vytváří virtuální prvek v DOMu.

Proč se píší dvě dvojtečky (::)?

  • Historie v CSS1 a CSS2: Původně se vše psalo s jednou dvojtečkou (např. :hover i :before).
  • Oddělení v CSS3: Specifikace CSS3 zavedla dvě dvojtečky (::) výhradně pro pseudoelementy, aby se na první pohled odlišily od stavových pseudotříd.
  • Zpětná kompatibilita: Prohlížeče pro ::before i ::after akceptují i starou jednu dvojtečku, ale správný a moderní zápis je vždy ::!
Rozlišení jedním pohledem:
:focus → stav prvku (pseudotřída)
::before → fiktivní element (pseudoelement)

Klíčové pseudoelementy v praxi

  • ::before a ::after: Vloží virtuální obsah před nebo za obsah elementu. Povinnost: Musí obsahovat vlastnost content: "", jinak se nevykreslí!
  • ::placeholder: Formátuje šedý nápovědný text uvnitř neobsazeného políčka <input>.
  • ::selection: Vzhled textu, který uživatel označil myší (barva výběru a pozadí).
  • ::marker: Formátuje odrážku nebo číslování u seznamů <li>. 
.tag::before {
  content: "#"; /* povinné! */
  color: #f97316;
}

Kaskáda, specificita a váhy selektorů

Jak prohlížeč matematicky rozhodne, které pravidlo zvítězí při konfliktu dvou různých stylů.

4úrovňový vektor váhy: (A, B, C, D)

Při kolizi stylů prohlížeč porovnává váhy zleva doprava (vyšší úroveň vždy přebije nižší):

A: Inline styl v HTML (style="...") 1, 0, 0, 0
B: ID selektory (#header) 0, 1, 0, 0
C: Třídy, atributy, pseudotřídy (.btn, [type], :hover) 0, 0, 1, 0
D: Značky elementů a pseudoelementy (p, ::before) 0, 0, 0, 1
Dvě pravidla pro řešení konfliktů

1. Vyšší specificita vítězí

Selektor #menu a (váha 0,1,0,1) bezpečně přebije selektor nav.main-nav ul li a (váha 0,0,1,4), ačkoliv je ten druhý delší!

2. Shodná specificita → Kaskáda (Pozice v kódu)

Mají-li dvě pravidla stejnou váhu, zvítězí to, které je v CSS souboru uvedeno níže.

Varování před !important:
Zvyšuje váhu mimo standardní systém. Začátečníci jej často používají k „opravě“ nefungujícího stylu, což vede k neudržitelné spirále chyb.

Souhrn a osvědčené postupy pro psaní selektorů

Zásady profesionálního webdesignu pro čistý, rychlý a udržitelný kód.

1. Preferujte třídy

  • Styly pište pomocí tříd (.class).
  • Vyhněte se stylům navázaným na ID (#header), protože znemožňují snadné znovupoužití a komplikují kaskádu.
  • Používejte rozumná pojmenování (např. metodiku BEM: .card__title).

2. Mělká specificita

  • Vyvarujte se dlouhých řetězců jako body div.wrapper section.content article p span.
  • Hluboké selektory zpomalují vykreslování a téměř nelze je přepsat jiným stylem.
  • Využívejte moderní :is() a :where().

3. Zákaz !important

  • Nikdy nepoužívejte !important jako záplatu pro špatně navrženou specificitu.
  • Pokud styl nefunguje, spočítejte si váhu selektorů a upravte strukturu pravidel, místo rozbíjení kaskády.

Ověření znalostí: Kontrolní otázky

Otestujte si pochopení selektorů, pseudotříd a specificity. Kliknutím si zobrazíte správné řešení.

1

Jaký je přesný rozdíl mezi selektory div p a div > p v DOM stromu?

Selektor div p používá kombinátor potomka (mezera) a vybere naprosto všechny odstavce nacházející se kdekoliv uvnitř <div>, i když jsou zanořené v dalších elementech (např. div > section > p). Naproti tomu div > p je přímý potomek (dítě) a vybere pouze odstavce, které leží bezprostředně na první úrovni přímo pod tímto <div>.
2

Které pravidlo zvítězí: #menu a (barva modrá) nebo nav.primary-nav ul li a.link (barva červená)? Zdůvodněte výpočtem specificity.

Zvítězí modrá barva (#menu a). Vypočítáme vektor specificity:
1. #menu a má 1 ID a 1 element → váha (0, 1, 0, 1).
2. nav.primary-nav ul li a.link má 2 třídy a 4 elementy → váha (0, 0, 2, 4).
Jelikož hodnota na pozici ID (druhé číslo zleva) je u prvního selektoru 1 a u druhého 0, první selektor jednoznačně vyhrává, i když je mnohem kratší.
3

Proč se u pseudoelementu ::before nic nevykreslí, pokud v CSS zapomenete uvést vlastnost content?

Dle specifikace W3C slouží pseudoelementy ::before a ::after ke generování virtuálního obsahu v render stromu prohlížeče. Výchozí hodnota vlastnosti content je normal (odpovídající none). Pokud vlastnost content explicitně nezadáte (postačí i prázdný řetězec content: "";), prohlížeč pseudoelement vůbec nevytvoří ani nevykreslí.
4

K čemu slouží revoluční pseudotřída :has() a proč se jí říká „rodičovský selektor“?

Pseudotřída :has() umožňuje naformátovat nadřazený element (nebo předchozího sourozence) na základě toho, jaké prvky obsahuje uvnitř sebe nebo v jakém stavu se nacházejí. Například form:has(:invalid) button[type="submit"] umožní vizuálně zakázat odesílací tlačítko, pokud libovolné pole formuláře není validní, aniž by k tomu byl potřeba JavaScript.
