TÉMA 033 Pozicování • 1D Layout

Pozicování a Flexbox

Běžný tok dokumentu (Normal Flow) a vytržení prvků z toku: relativní, absolutní, fixní a lepivé pozicování (relative, absolute, fixed, sticky) se souřadnicemi. Třetí rozměr v CSS: vrstvení z-index a nástrahy nového Stacking Contextu. Pružné jednorozměrné rozvržení Flexbox: kontejner (display: flex), hlavní a příčná osa (flex-direction), zalamování (flex-wrap), zarovnávání (justify-content, align-items, gap) a pružnost položek (grow, shrink, basis).

TÉMA 034 CSS Grid • 2D Rozvržení

Dvourozměrný nativní systém rozvržení celého webu v řádcích i sloupcích současně (display: grid). Zlomková jednotka fr a funkce repeat(), mezery gap a zarovnávání. Umisťování prvků po liniích (grid-column/row) a šablonové oblasti grid-template-areas (ASCII art v CSS). Magická responzivní mřížka bez media queries s repeat(auto-fit, minmax()), automatické doplňování dense a rozhodovací matice Flexbox vs. CSS Grid.

TÉMA 037 a11y • Přístupnost

Webová přístupnost (a11y) v CSS

Standardy bezbariérového webu (WCAG 2.1) a principy POUR. Kontrastní poměry barev (4.5:1 pro běžný text, 3:1 pro velký text). Nebezpečí outline: none a moderní řešení pomocí :focus-visible pro ovládání klávesnicí. Čtečky obrazovek a technika .sr-only vs. display: none. Jednotky rem pro respekt ke zvětšování písma, daltonismus a doplňování barev o ikony, dotykové terče 44x44 px a ochrana před kinetózou (prefers-reduced-motion).
