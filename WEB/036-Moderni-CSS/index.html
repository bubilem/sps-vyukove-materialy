CSS Custom Properties: Nativní proměnné v CSS

Definujte barvy, rozměry a písma na jednom místě a měňte je za běhu v celém projektu.

Definice na :root

Syntaxe se dvěma pomlčkami (--)

Globální proměnné definujeme v pseudotřídě :root (odpovídá kořenovému elementu <html>): 

:root {
  --primary-color: #6366f1;
  --base-padding: 1rem;
  --border-radius: 8px;
}

Názvy proměnných rozlišují velká a malá písmena (jsou case-sensitive). --Primary a --primary jsou dvě různé věci!

Čtení hodnoty: var()

Použití funkce var() s fallbackem

Proměnnou vložíme na místo jakékoliv hodnoty:

.btn-primary {
  background-color: var(--primary-color);
  padding: var(--base-padding);
  border-radius: var(--border-radius);
}

/* Záchranná záložní hodnota (fallback): */
color: var(--custom-accent, #3b82f6);

Kaskáda a rozsah (Scope) CSS proměnných

Na rozdíl od preprocesorů (Sass) jsou CSS proměnné živou součástí DOM stromu a podléhají dědičnosti.

Lokální předefinování hodnot

Proměnnou můžete uvnitř konkrétní komponenty jednoduše přepsat – změna se projeví pouze uvnitř této komponenty a jejích potomků: 

.card {
  --card-accent: #6366f1; /* Výchozí barva */
  border-color: var(--card-accent);
}

/* Změna barvy pro chybovou kartu bez přepisu vlastností: */
.card.card-error {
  --card-accent: #f43f5e;
}

Dostupnost v JavaScriptu

CSS proměnné lze za běhu číst i dynamicky měnit pomocí JavaScriptu:

// Změna barvy motivu uživatele kliknutím:
document.documentElement.style
  .setProperty('--primary-color', '#10b981');

// Přečtení aktuální hodnoty:
getComputedStyle(element)
  .getPropertyValue('--primary-color');

Přepínač témat (Light / Dark) čistě přes proměnné

Změnou jediné třídy nebo atributu přebarvíte celý komplexní web bez duplikace CSS pravidel.

Definice palet na rootu 
/* Výchozí světlý motiv: */
:root, [data-theme="light"] {
  --bg-main: #ffffff;
  --bg-card: #f8fafc;
  --text-main: #0f172a;
  --border: #e2e8f0;
}

/* Tmavý motiv při aktivaci atributu: */
[data-theme="dark"] {
  --bg-main: #0f172a;
  --bg-card: #1e293b;
  --text-main: #f8fafc;
  --border: #334155;
}
Jednoduchá aplikace na komponentách 
body {
  background: var(--bg-main);
  color: var(--text-main);
}

.card {
  background: var(--bg-card);
  border: 1px solid var(--border);
}

Žádné další selektory ani složité kaskády nepotřebujete. Tlačítko v HTML pouze přepne atribut document.documentElement.dataset.theme = 'dark';.

Nativní CSS Nesting (Zanořování pravidel)

Dlouhá léta hlavní důvod k instalaci Sassu – dnes plně podporovaný standard přímo v prohlížeči.

Tradiční CSS (Bez zanoření) 
.card {
  padding: 1.5rem;
}
.card h3 {
  margin-top: 0;
}
.card:hover {
  transform: translateY(-2px);
}
.card .btn {
  background: #6366f1;
}
Moderní CSS Nesting se znakem & 
.card {
  padding: 1.5rem;

  & h3 {
    margin-top: 0;
  }

  &:hover {
    transform: translateY(-2px);
  }

  & .btn {
    background: #6366f1;
  }
}

Znak & představuje odkaz na nadřazený selektor. Kód je modulární, přehledně zabalený do jednoho bloku.

Kombinace různých jednotek: Funkce calc()

Umožňuje provádět matematické operace (+, -, *, /) mezi procenty, pixely, rem a viewport jednotkami.

Příklady praktického využití

/* Šířka celého rodiče mínus pevný 40px okraj: */
width: calc(100% - 40px);

/* Výška přesně na zbytek okna pod 60px hlavičkou: */
min-height: calc(100vh - 60px);

/* Výpočet mřížky: */
width: calc((100% - 2rem) / 3);

Kritické pravidlo: Mezery kolem operátorů!

U operátorů sčítání (+) a odčítání (-) musí být vždy mezera z obou stran: 

width: calc(100% - 20px);  /* SPRÁVNĚ */
width: calc(100%-20px);   /* CHYBA! Prohlížeč kód zahodí! */

Důvod: zápis -20px prohlížeč chápe jako záporné číslo, ne jako matematické odčítání.

Omezovací funkce a fluidní typografie: min, max a clamp

Zajistěte, aby písmo i boxy plynule rostly s velikostí okna, ale nikdy nepřekročily bezpečné meze.

min() a max()
  • min(A, B): Vybere tu menší z hodnot. Vynikající pro responzivní šířku: 
    width: min(100%, 800px); /* Nahrazuje max-width! */
  • max(A, B): Vybere tu větší z hodnot. Vynikající pro bezpečný minimální rozměr.
Revoluce: clamp(min, pref, max)

Přijímá 3 parametry: minimální mez, preferovanou pružnou hodnotu a maximální strop:

/* Fluidní nadpis: na mobilu 24px, plynule roste, max 48px */
h1 {
  font-size: clamp(1.5rem, 4vw + 0.5rem, 3rem);
}

Už žádné skokové zvětšování písma přes pět různých Media queries – písmo se plynule zvětšuje s každým jedním pixelem monitoru.

Kaskádové vrstvy (@layer): Konec válek se specificitou

Rozdělte svůj kód do logických architektonických vrstev, kde vyšší vrstva vždy přebije nižší.

Řád a architektura ve velkém CSS

Dříve styl z knihovny třetí strany s těžkým selektorem (např. #nav .item a) nešlo přepsat naší jednoduchou utilitou .hidden. S @layer to vyřešíte jednoduše: 

/* 1. Definujeme pořadí priorit (zleva doprava): */
@layer reset, base, components, utilities;

Pravidlo ve vrstvě utilities vždy zvítězí nad pravidlem v components, bez ohledu na to, jak složitý selektor komponenta má!

Zápis pravidel do vrstev 
@layer components {
  .btn {
    background: #6366f1;
    color: white;
  }
}

@layer utilities {
  .bg-danger {
    background: #f43f5e; /* Přebije .btn bez !important */
  }
}

Barevné funkce nové generace: color-mix() a OKLCH

Míchejte odstíny, vytvářejte průhlednosti a využívejte moderní displeje s širokým gamutem.

Funkce color-mix()

Umožňuje smíchat dvě barvy v zadaném poměru v daném barevném prostoru:

/* Vytvoření 20% poloprůhledné varianty tlačítka: */
background: color-mix(in srgb, var(--primary) 20%, transparent);

/* Ztmavení barvy přimícháním 15 % černé: */
background: color-mix(in srgb, var(--primary), black 15%);

Barevný prostor OKLCH

Tradiční RGB/HSL má problémy s vnímáním lidského oka (např. čistě žlutá se zdá mnohem jasnější než modrá se stejným procentem světlosti). 

/* Světlost (L), sytost (C), odstín ve stupních (H) */
color: oklch(0.7 0.15 150);

OKLCH je perceptuálně lineární a dokáže zobrazit zářivější barvy na moderních P3 displejích (MacBooky, nové iPhony).

Doporučená architektura moderního CSS souboru

Jak strukturovat profesionální stylopis, aby se v něm neztratil ani velký vývojový tým.

1. Design Tokeny (:root)

Na samém začátku definujeme globální proměnné: barevnou paletu, typografické stupnice, mezery a stíny.

2. CSS Reset & Base

Nastavení box-sizing: border-box, pružných obrázků (max-width: 100%) a výchozí typografie pro body a nadpisy.

3. Samostatné komponenty

Každá komponenta (.card, .navbar, .modal) je zapouzdřena pomocí nativního CSS nestingu a lokálních proměnných.

Shrnutí tématu a opakovací otázky

Ověřte si své porozumění moderním CSS proměnným, nestingu, clampu a kaskádovým vrstvám.

01. V čem se zásadně liší CSS proměnné (Custom Properties) od proměnných v Sassu ($color)?
Proměnné v Sassu existují pouze během překladu na serveru/v počítači – do výsledného CSS se propíší jako statické hodnoty. CSS Custom Properties žijí přímo v DOM stromu prohlížeče za běhu stránky, podléhají kaskádové dědičnosti a lze je okamžitě měnit JavaScriptem i Media queries.
02. Proč je v matematické funkci calc() nutné psát mezery kolem znamének + a -?
Znak - bez mezery (např. -20px) CSS parser interpretuje jako zápornou hodnotu jednotky, nikoliv jako operátor odčítání. Syntaxe calc(100%-20px) je tedy syntaktická chyba a prohlížeč celé pravidlo zahodí.
03. K čemu slouží funkce clamp(min, preferred, max) a co vyřešila v typografii?
Umožňuje vytvořit fluidní velikost textu i mezer. Písmo plynule roste s šířkou viewportu (např. 3vw), ale nikdy neklesne pod nastavené minimum (na mobilu) ani nepřekročí nastavené maximum (na velkém monitoru). Nahrazuje desítky skokových Media queries.
04. Jaký problém řeší kaskádové vrstvy @layer?
Umožňují explicitně seřadit prioritu stylů do vrstev (např. reset, base, components, utilities). Styl ve vyšší vrstvě vždy zvítězí nad stylem v nižší vrstvě bez ohledu na to, jak vysokou specificitu selektor v nižší vrstvě má. Zabraňuje válkám se specificitou a zneužívání !important.
