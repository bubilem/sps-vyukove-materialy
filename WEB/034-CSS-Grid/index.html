CSS Grid a 2D rozvržení

Ovládněte celostránkový layout v obou rozměrech současně • Od definice řádků a sloupců přes zlomkovou jednotku fr, funkci repeat() a minmax() až po vizuální šablonové oblasti grid-template-areas a responzivní automatické plnění auto-fit.

Základní 2D mřížka

display: grid, řádky, sloupce, mezery gap a zásadní rozdíl oproti 1D Flexboxu.

Jednotka fr & repeat()

Pružné dělení zbývajícího prostoru poměrovým zlomkem bez počítání procent.

Template Areas

Vizuální ASCII mapování rozvržení stránky: header, nav, main, sidebar, footer.

Od tabulek k nativní 2D mřížce: display: grid

Zatímco Flexbox řeší jednu osu, CSS Grid vytváří skutečnou dvourozměrnou matici řádků a sloupců.

Aktivace a definice mřížky

Mřížku aktivujeme nastavením display: grid; na rodičovském kontejneru. Následně definujeme strukturu sloupců a řádků: 

.container {
  display: grid;
  grid-template-columns: 200px 300px 200px;
  grid-template-rows: 100px 200px;
}

Tento zápis vytvoří mřížku o 3 sloupcích a 2 řádcích. Všechny přímé děti se automaticky zařadí do jednotlivých buněk (cells).

Základní terminologie Gridu
  • Grid Container (Kontejner): Rodičovský element s display: grid.
  • Grid Item (Položka): Každé přímé dítě kontejneru.
  • Grid Lines (Linky / Osy): Číslované dělící čáry ohraničující řádky a sloupce (začínají od 1).
  • Grid Track (Stopa): Prostor mezi dvěma sousedními linkami (jeden řádek nebo jeden sloupec).
  • Grid Cell (Buňka): Jedno políčko na průsečíku řádku a sloupce.

Pružná zlomková jednotka fr a funkce repeat()

Revoluční jednotka vytvořená speciálně pro CSS Grid: konec ručního přepočítávání procent a zaokrouhlovacích chyb.

Fractional Unit (fr)

Co je to jednotka fr?

Představuje podíl na zbývajícím volném prostoru (fraction). Prohlížeč nejdříve odečte pevné pixely a zbytek rozdělí podle součtu zlomků. 

/* Levý panel pevný, zbytek se dělí v poměru 2:1 */
grid-template-columns: 250px 2fr 1fr;
  • Pokud mají sloupce 1fr 1fr 1fr, má každý přesně třetinu dostupného místa.
  • Zabrání horizontálnímu přetečení, které často způsobují neopatrná procenta s marginy.
Zkrácení zápisu

Funkce repeat(počet, rozměr)

Místo opakování stejných hodnot použijeme elegantní funkci:

/* 12sloupcový responzivní grid jako v Bootstrapu: */
grid-template-columns: repeat(12, 1fr);

/* Střídavý vzor sloupců: */
grid-template-columns: repeat(3, 100px 1fr);

Zápis repeat(4, 1fr) je přesně totožný jako 1fr 1fr 1fr 1fr, ale mnohonásobně čitelnější.

Mezery v mřížce (gap) a zarovnávání buněk

Čisté oddělení položek a kontrola nad zarovnáním obsahu uvnitř buněk.

Mezery mezi řádky a sloupci

Grid má špičkovou nativní podporu pro mezery:

row-gap: 20px;     /* Mezera mezi řádky */
column-gap: 30px;  /* Mezera mezi sloupci */
/* Nebo souhrnná zkratka: gap: [row] [column]; */
gap: 20px 30px;
gap: 1.5rem;       /* Shodná mezera v obou směrech */

Mezera vzniká výhradně mezi stopami. Vnější okraje mřížky zůstávají čisté a neovlivněné.

Zarovnávání: items vs. content

  • justify-items (vodorovně uvnitř buňky): stretch (výchozí), start, center, end.
  • align-items (svisle uvnitř buňky): stretch, start, center, end.
  • place-items: center;: Okamžitě vycentruje obsah všech buněk na vodorovný i svislý střed!
Jednotlivé prvky mohou výchozí zarovnání přebít pomocí justify-self a align-self.

Umisťování prvků po liniích: grid-column a grid-row

Roztahování prvků přes více sloupců či řádků pomocí čísel dělících linek nebo klíčového slova span.

Číslování linek (1, 2, 3...)

Syntaktický zápis: odkud / kam

Pokud máme 3 sloupce, vzniknou celkem 4 vertikální linky. Prvek může začínat na libovolné lince a končit na jiné: 

.banner {
  /* Od linky 1 po linku 4 (přes všechny 3 sloupce): */
  grid-column: 1 / 4;
}

.sidebar {
  /* Přes dva řádky shora dolů: */
  grid-row: 1 / 3;
}
Pokročilé triky: span a záporné indexy

Klíčové slovo span a index -1

  • grid-column: span 2;: Roztáhne prvek přes 2 sloupce od jeho aktuální pozice, aniž byste museli znát konkrétní čísla linek.
  • Záporný index -1: Označuje úplně poslední linku mřížky.
/* Roztažení přes celou šířku od kraje ke kraji: */
.header-full {
  grid-column: 1 / -1;
}

Vizuální skládání layoutu: grid-template-areas

Pojmenujte části stránky a složte celou kostru webu jako ASCII obrázek přímo v CSS.

Definice na kontejneru

Pojmenovaná mřížka v uvozovkách

.layout {
  display: grid;
  grid-template-columns: 220px 1fr 200px;
  grid-template-areas:
    "header  header  header"
    "nav     main    aside"
    "footer  footer  footer";
  gap: 1rem;
}

Pokud chcete nechat některou buňku prázdnou, napíšete místo názvu tečku (".").

Přiřazení prvkům: grid-area

Napojení HTML elementů na oblasti

Každému HTML elementu pouze přiřadíte jeho název z mřížky:

header { grid-area: header; }
nav    { grid-area: nav; }
main   { grid-area: main; }
aside  { grid-area: aside; }
footer { grid-area: footer; }

Kouzlo pro responsivitu: V media query pro mobil stačí změnit pouze jedinou vlastnost grid-template-areas: "header" "nav" "main" "aside" "footer"; a rozvržení se samo přestaví pod sebe!

Magická responzivní mřížka: auto-fit a minmax()

Svatý grál moderního webdesignu: mřížka karet, která se dokonale přizpůsobuje bez jediného Media Query.

Řádek kódu za milion dolarů 
.cards-grid {
  display: grid;
  grid-template-columns: 
    repeat(auto-fit, minmax(260px, 1fr));
  gap: 1.5rem;
}

Jak to funguje krok za krokem:

  • minmax(260px, 1fr): Karta nesmí mít méně než 260px, ale pokud je místa dostatek, roztáhne se na 1fr.
  • auto-fit: Prohlížeč spočítá, kolik sloupců o šířce min. 260px se do okna vejde. Zbytek roztáhne.
Rozdíl: auto-fit vs. auto-fill

Kdy použít který režim?

  • auto-fit (doporučeno): Vyprázdněné sloupce složí (zkolabuje) na šířku 0px a existující karty se roztáhnou přes celou šířku kontejneru.
  • auto-fill: Rezervuje prázdné sloupce v mřížce, i když pro ně v HTML nemáte žádný obsah (karty se neroztáhnou).
Závěr: Pro e-shopy, galerie a portfolia karet téměř vždy volíme auto-fit!

Implicitní mřížka a automatické doplňování (dense)

Co se stane, když do mřížky dorazí více prvků, než kolik jste předem nadefinovali.

Explicitní vs. Implicitní

Co když prvky přetečou?

Explicitní mřížka: Řádky a sloupce zadané ručně v grid-template-*.
Implicitní mřížka: Řádky, které prohlížeč automaticky vytvoří, když počet prvků přesáhne kapacitu explicitní mřížky. 

.container {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  /* Velikost automaticky přibývajících řádků: */
  grid-auto-rows: minmax(120px, auto);
}
Kouzlo Tetrisu: dense flow

grid-auto-flow: dense;

Pokud některé položky v mřížce zabírají 2 sloupce a jiné 1, mohou v mřížce vznikat prázdné díry. 

.bento-grid {
  grid-auto-flow: dense; /* Zaplní prázdné díry menšími prvky! */
}

Prohlížeč prochází prvky a pokud narazí na malý prvek, který se vejde do předchozí díry, vloží ho tam. Skvělé pro fotogalerie a Bento mřížky.

Kdy použít Flexbox a kdy CSS Grid?

Rozhodovací matice a pravidla, jak obě technologie kombinovat v harmonický celek.

Vlastnost Flexbox (1D) CSS Grid (2D)
Dimenzionalita Jednorozměrný (buď řádek, NEBO sloupec). Dvourozměrný (řádky I sloupce současně).
Filozofie návrhu Content-first: Velikost a polohu určuje obsah prvků. Layout-first: Prvky se podřizují předem definované mřížce.
Ideální využití Navigační lišty, tlačítka s ikonou, formulářové řádky, centrování. Celostránková kostra webu, galerie, dashboardy, složité karty.
Překrývání prvků Obtížné (vyžaduje position: absolute). Nativní – dva prvky lze umístit na stejné souřadnice buňky!
Zlaté pravidlo profesionála:
Použijte CSS Grid pro celkový layout stránky (header, sidebar, content) a uvnitř jednotlivých komponent použijte Flexbox pro zarovnání detailů (logo + menu, avatar + jméno).

Klasický „Svatý grál“ (Holy Grail Layout) v moderním pojetí

Jak postavit plnohodnotnou webovou aplikaci na pouhých 15 řádcích čistého CSS bez JavaScriptu.

HTML struktura 
<div class="app-layout">
  <header>Hlavička s logem</header>
  <nav>Levá navigace</nav>
  <main>Hlavní obsah stránky</main>
  <aside>Pravý panel akcí</aside>
  <footer>Patička webu</footer>
</div>
Kompletní CSS kód 
.app-layout {
  display: grid;
  min-height: 100vh;
  grid-template-columns: 220px 1fr 200px;
  grid-template-rows: auto 1fr auto;
  grid-template-areas:
    "header header header"
    "nav    main   aside"
    "footer footer footer";
}
header { grid-area: header; }
nav    { grid-area: nav; }
main   { grid-area: main; }
aside  { grid-area: aside; }
footer { grid-area: footer; }

Shrnutí tématu a opakovací otázky

Ověřte si své porozumění CSS Gridu, jednotce fr, auto-fitu a šablonovým oblastem.

01. V čem se liší jednotka 1fr od zápisu 100% nebo 33.33%?
Jednotka fr představuje podíl ze zbývajícího volného místa po odečtení pevných pixelů a mezer (gap). Nemusíte počítat zaokrouhlovací chyby ani řešit přetečení jako u procent, kde by gap mohl způsobit nechtěný scrollbar.
02. Co přesně znamená zápis grid-column: 1 / -1;?
Číslo 1 znamená první vertikální linku mřížky (levý okraj). Záporný index -1 označuje úplně poslední linku mřížky (pravý okraj). Prvek se tedy roztáhne přes celou dostupnou šířku mřížky bez ohledu na to, kolik má sloupců.
03. Proč je kombinace repeat(auto-fit, minmax(250px, 1fr)) tak populární?
Vytváří plně responzivní mřížku karet zcela bez použití @media pravidel. Karty automaticky přeskakují do 1, 2, 3 nebo 4 sloupců podle aktuální šířky obrazovky a současně se přirozeně roztahují tak, aby nezůstávalo žádné prázdné místo.
04. Kdy je vhodnější sáhnout po Flexboxu a kdy po CSS Gridu?
CSS Grid volíme pro dvourozměrný celostránkový layout (kostra webu: header, navigace, main, patička, fotogalerie). Flexbox volíme pro jednorozměrné komponenty a zarovnání obsahu uvnitř prvků (navigační lišta, centrování tlačítka, ikona s textem, patička karty).
