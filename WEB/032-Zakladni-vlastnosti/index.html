Typografie a vlastnosti pro formátování textu

Čitelnost textu je nejdůležitějším faktorem webu. Zásady volby fontů, výšky řádku a zarovnání.

Písmo a Fallback Font Stack

  • font-family: Seznam písem oddělených čárkou. Prohlížeč zkouší písma zleva doprava a použije první dostupné: 
    font-family: 'Inter', system-ui, -apple-system, sans-serif;
    Obecné rodiny na konci stacku: sans-serif (bezpatkové), serif (patkové), monospace (neproporcionální pro kód).
  • font-size: Velikost písma (doporučeno v rem, např. 1rem pro tělo, 1.5rem–2.5rem pro nadpisy).
  • font-weight: Tloušťka řezu (čísla: 400 normální, 600 polotučné, 700 tučné bold).
  • font-style: Kurzíva (italic / normal).

Výška řádku a formátování odstavců

  • line-height (Zásadní pravidlo): Udává výšku řádku. Zapisujte ji bez jednotky (např. 1.5 až 1.6). Bezrozměrné číslo se správně dědí podle velikosti písma potomků bez nežádoucího překrývání!
  • text-align: Horizontální zarovnání: left, center, right, justify (do bloku – na webu nepoužívat kvůli nevzhledným mezerám).
  • text-decoration: Podtržení odkazů (underline, none, barva a styl: underline wavy orange).
  • text-transform: Převod velikosti písmen: uppercase (velká), lowercase, capitalize (první velká).
  • letter-spacing: Prostrkání znaků (např. 0.05em u tlačítek psaných velkými písmeny).

Barvy a pozadí prvku: Vlastnosti background-*

Jak prvku nastavit podkladovou barvu, obrázek a správně kontrolovat jeho chování při změně rozlišení.

Jednotlivé vlastnosti pozadí
  • color: Barva textu (např. #f8fafc).
  • background-color: Plná podkladová barva za obsahem a paddingem.
  • background-image: Cesta k obrázku pomocí funkce url('cesta/k/obrazku.webp').
  • background-repeat: Opakování tapety: no-repeat (nejčastější), repeat-x, repeat.
  • background-position: Umístění obrázku v rámci prvku: center, top right, 50% 50%.
  • background-size (Klíčová responzivita):
    • cover: Roztáhne obrázek tak, aby zcela pokryl celou plochu (ořízne přesahy).
    • contain: Zmenší obrázek tak, aby byl celý vidět (mohou vzniknout prázdné pruhy).
Zkrácený zápis (Shorthand)

Všechny vlastnosti lze zapsat na jeden řádek pomocí vlastnosti background:

/* Typická hero sekce: */
.hero-banner {
  background: #0f172a url('bg.webp') no-repeat center / cover;
  color: #ffffff;
  min-height: 60vh;
}
Pozor na syntaxi lomítka (/):
V shorthandu background se background-size zapisuje za pozici oddělené lomítkem: center / cover. Vždy uvádějte i záložní background-color pro případ, že se obrázek nepodaří stáhnout!

Moderní CSS gradienty na pozadí

Vytváření hladkých barevných přechodů čistě v CSS bez nutnosti načítat rastrové obrázky.

1. Lineární přechod: linear-gradient()

Přechází v přímém směru pod zadaným úhlem nebo směrem (to right, to bottom, 135deg):

.tlacitko-akce {
  background: linear-gradient(135deg, #f97316, #ea580c);
}

/* Přechod s procentuálními zarážkami: */
.duha {
  background: linear-gradient(to right, #f43f5e 0%, #38bdf8 100%);
}
linear-gradient(135deg, #f97316, #ea580c)
2. Radiální přechod & Vrstvení

Kruhový přechod ze středu ven nebo poloprůhledné ztmavení fotografie:

/* Ztmavení fotky pro lepší čitelnost bílého textu: */
.karta-hero {
  background:
    linear-gradient(rgba(0,0,0,0.6), rgba(0,0,0,0.6)),
    url('foto.webp') center / cover;
}
radial-gradient(circle, #38bdf8, #0369a1)

Rámečky (Border), zaoblení a obrysy (Outline)

Vymezení hranic elementů, zaoblování rohů a zásadní rozdíl mezi Border a Outline.

Rámeček a zaoblení rohů
  • border (Shorthand): Sdružuje tloušťku, styl a barvu: 
    border: 2px solid #f97316;
    Styly rámečku: solid (plná čára), dashed (čárkovaná), dotted (tečkovaná), none.
  • border-radius (Kulaté rohy):
    • Mírné zaoblení: border-radius: 8px;
    • Pilulkové tlačítko: border-radius: 9999px;
    • Dokonalý kruh: border-radius: 50%; (při shodné šířce a výšce prvků např. profilový avatar 48×48px).
Zásadní rozdíl: Border vs. Outline

Border (Rámeček)

Je pevnou součástí Box modelu. Zabírá fyzické místo v layoutu a může posouvat okolní obsah (pokud nepoužíváte border-box).

Outline (Vnější obrys)

Kreslí se vně rámečku a nezabírá žádné místo v toku dokumentu. Nikdy nerozhodí layout! Lze odsadit pomocí outline-offset.

Zásada přístupnosti (a11y):
Nikdy nenastavujte outline: none; bez adekvátní náhrady! Uživatelé navigující klávesnicí by neviděli, kde se právě nachází fokus.

Stíny a prostorová hloubka: box-shadow

Vytváření plastičnosti a vizuálního vyvýšení prvků (Elevation) nad rovinu stránky.

Anatomie vlastnosti box-shadow

Pořadí parametrů stínu v CSS:

box-shadow: offsetX offsetY blurRadius spreadRadius color [inset];
  • offsetX / offsetY: Vodorovný a svislý posun stínu (kladný Y = stín padá dolů).
  • blurRadius: Poloměr rozostření (0 = ostrá hrana, vyšší = měkký stín).
  • spreadRadius: Roztažení stínu do šířky (volitelné).
  • color: Barva stínu (doporučeno poloprůhledná černá rgba(0, 0, 0, 0.15)).
  • inset: Vnitřní stín (vpadlý do elementu).
Vrstvené stíny pro přirozený vzhled

Profesionální designové systémy nespoléhají na jediný tvrdý stín, ale vrství dva měkké stíny přes čárku:

/* Přirozený moderní stín karty: */
.modern-card {
  box-shadow:
    0 4px 6px -1px rgba(0, 0, 0, 0.1),
    0 2px 4px -2px rgba(0, 0, 0, 0.1);
}

/* Text-shadow: posunX posunY rozostření barva */
.titulek {
  text-shadow: 0 2px 4px rgba(0, 0, 0, 0.5);
}

Režimy zobrazení a toku dokumentu: display

Jakým způsobem se prvek zapojuje do normálního toku stránky: řádkový vs. blokový prvek.

display: block;

Blokový prvek

Začíná na novém řádku a roztáhne se na 100% šířky rodiče.

  • Plně reaguje na width a height.
  • Plně reaguje na všechny okraje margin i padding.
  • Výchozí pro: div, p, h1-h6, section, ul.
display: inline;

Řádkový prvek

Proudí uvnitř textu vedle ostatních slov. Nezačíná na novém řádku.

  • Ignoruje width a height.
  • Vertikální margin-top/bottom neovlivňují tok řádků!
  • Výchozí pro: span, a, strong, em.
display: inline-block;

Kombinovaný hybrid

Zůstává v řádku vedle ostatních prvků, ale chová se uvnitř jako blok.

  • Lze mu nastavit fixní width a height.
  • Plně respektuje vertikální padding i margin.
  • Ideální pro: tlačítka, odznáčky a ikonové štítky.
display: none;

Kompletní skrytí

Element je zcela vyjmut z renderovacího stromu.

  • Nezabírá žádné místo na stránce (okolní obsah se sesune).
  • Nereaguje na kliknutí.
  • Čtečky obrazovky jej zcela ignorují.

Tři způsoby skrytí: display: none vs. visibility vs. opacity

Častá otázka u technických pohovorů a klíčový koncept pro animace a přístupnost.

Vlastnost Zabírá místo v layoutu? Reaguje na myš / klik? Lze plynule animovat? Čtečka obrazovky
display: none; NE (zmizí i prostor) NE NE (skoková změna) Ignoruje
visibility: hidden; ANO (zůstane prázdná díra) NE (proklikne skrz) Omezeně (pouze viditelnost) Ignoruje
opacity: 0; ANO (zůstane prázdná díra) ANO (prvek stále kliká!) ANO (ideální pro transition) Přečte obsah!
Tip z praxe:
Pokud animujete postupné mizení prvku (fade out), použijte opacity: 0 s CSS přechodem a po skončení animace nastavte pointer-events: none (aby neviditelný prvek neblokoval kliknutí pod sebou).

Přetékání obsahu: Vlastnost overflow

Co se stane, když je text, tabulka nebo obrázek větší než pevně vymezená krabička rodiče.

Výchozí

overflow: visible;

Obsah nepřirozeně přeteče ven z krabičky a překryje okolní text nebo grafiku na stránce.

Tento dlouhý text přeteče ven přes rámeček rodiče a nekontrolovaně pokračuje dál...
Oříznutí

overflow: hidden;

Vše, co přesahuje hranice boxu, je nekompromisně oříznuto a skryto. Žádné posuvníky.

Tento dlouhý text je oříznut přesně na hraně výšky rodičovského bloku a zbytek není vidět...
Trvalý posuvník

overflow: scroll;

Vždy zobrazí posuvníky (vertikální i horizontální), i když obsah vůbec nepřetéká.

Posuvník je zobrazen natvrdo.
Inteligentní auto

overflow: auto;

Posuvník se objeví pouze tehdy, když je obsah skutečně delší než rozměry krabice.

Praktický standard pro kódové bloky a responzivní tabulky (overflow-x: auto).

Ověření znalostí: Kontrolní otázky

Otestujte si pochopení základních vlastností, toku prvků a typografie. Kliknutím zobrazíte odpověď.

1

Proč se u vlastnosti line-height doporučuje zadávat hodnotu jako bezrozměrné číslo (např. 1.5) a ne v pixelech (např. 24px)?

Bezrozměrné číslo funguje jako násobič aktuální velikosti písma. Pokud rodičovský prvek předá dětem line-height: 1.5, každý vnořený element (např. velký nadpis i malý popisek) si spočítá výšku řádku jako 1.5-násobek svého vlastního font-size. Pokud byste zadali fixních 24px, velký nadpis s písmem 32px by se ošklivě zhroutil a řádky by se překryly přes sebe.
2

Máte prvek <span> s nastavenou šířkou width: 200px; margin-top: 30px;, ale šířka ani horní okraj se neprojeví. Proč a jak to opravit?

Element <span> má výchozí zobrazení display: inline. Čistě řádkové prvky z principu ignorují vlastnosti width, height i vertikální margin-top / margin-bottom. Řešením je změnit režim zobrazení na display: inline-block; (pokud má zůstat v toku textu) nebo display: block;.
3

Jaký je rozdíl mezi background-size: cover a background-size: contain při změně velikosti okna?

Hodnota cover roztáhne obrázek tak, aby zcela pokryl celou plochu elementu. Poměr stran zůstává zachován, ale části obrázku mohou být po stranách oříznuty. Naproti tomu contain zmenší nebo zvětší obrázek tak, aby se celý vešel dovnitř elementu bez jakéhokoliv oříznutí, což ale může zanechat prázdné pruhy po stranách.
4

Jak jednoduše vytvořit v CSS kruhový profilový obrázek a jak zajistit, aby se nedeformoval?

Prvku nastavíme shodnou šířku a výšku (např. width: 64px; height: 64px;) a zaoblení rohů border-radius: 50%;. Proti deformaci (zploštění) fotografie navíc přidáme vlastnost object-fit: cover;, která se chová analogicky jako background-size a zachová správný poměr stran snímku.
